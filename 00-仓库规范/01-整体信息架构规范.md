# 整体信息架构规范

## 1. 架构原则
- 理论知识、案例证据、技术研究、设计实践分层管理。
- 一个知识主题设置一个权威文档；其他位置使用链接，不复制正文。
- 案例按主表现类型归档，辅助类型通过索引关联。
- 数据逻辑、表现类型、基础设计方法和统计技术保持概念边界。
- 项目工作区与长期知识库分离，项目结论经验证后再回写知识库。

## 2. 一级模块
00 仓库规范；01 信息图形数据逻辑；02 信息图形类型案例；03 统计图形分析；04 Gestalt；05 ISOTYPE；06 主题设计项目；07 设计经验与知识回写；08 模板与参考资料。

## 3. 内容流转
理论提出分类框架 → 案例提供证据 → 分析检验框架 → 项目实践验证方法 → 经验模块沉淀规律 → 回写理论、标签和模板。

## 4. 目录职责
README 负责入口与范围；标签说明负责分类定义；分析文档负责个案证据；模板负责新建内容的结构；规范文档负责约束流程。
