# 注释与证据标记规范

## 1. 证据等级
- E1｜原始事实：原始作品、原始数据、正式出版资料或可核验的一手来源。
- E2｜观察记录：从当前可见图像、文本或数据直接观察到的现象。
- E3｜分析推断：依据 E1/E2 与理论形成的解释，必须说明推理依据。
- E4｜待核实：来源、口径、制作过程或其他关键证据不足。

证据等级描述材料与判断的关系，不是对来源机构的简单排名。

## 2. 推荐写法
每项重要结论注明“结论—证据—推理—限制”。事实与推断分段表达；不能把视觉相似性直接写成数据关系或因果关系。

## 3. 注释块
可使用 GitHub Markdown 提示块：
> [!NOTE]
> 说明性备注。
> [!WARNING]
> 证据缺口或误读风险。

提示块用于强调，不替代正文中的来源引用。

## 4. 不确定性
使用“待核实”“证据不足”“暂定判断”等明确措辞，并写明需要补充什么材料、由什么证据解决。
