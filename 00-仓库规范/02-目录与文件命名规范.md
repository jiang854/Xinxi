# 目录与文件命名规范

## 1. 目录
一级模块使用两位数字前缀，如 01-信息图形数据逻辑。模块内分类目录使用两位数字前缀。目录名称应简洁、稳定且表达内容职责。

## 2. 文件
- 模块入口统一 README.md。
- 分类定义统一使用 00-标签说明.md。
- 理论文档使用两位数字前缀。
- Gestalt 原则使用 G01—G13 稳定编号。
- 案例文件夹使用 CASE-四位数字-主题名称。
- 模板文件以“模板”结尾；规范文件以“规范”结尾。

## 3. 案例编号
旧编号应在迁移说明中保留映射。编号一经发布不因分类变化而重用。

## 4. 文件名字符
优先使用中文、数字和连字符；避免空格、临时版本词和无意义缩写。英文术语可作为辅助检索词。

## 5. 迁移
移动或重命名文件时同步更新 Markdown 相对链接、索引和文档内引用，并保留历史编号映射。
