# Markdown 文档写作规范

## 1. 标题结构
每份文档仅使用一个一级标题；章节依次使用二级、三级标题，不跳级。章节编号采用“一、二”或“1.1”中的一种并保持一致。

## 2. 文档元信息
重要研究文档建议在标题下记录所属模块、文档属性、状态、版本、创建日期和更新日期。缺失信息写“待填写”，不得猜测。

## 3. 正文表达
先定义问题和范围，再给证据、分析和结论。术语首次出现时给出中英文名称；表格用于结构化比较，列表用于并列项目。

## 4. 链接与图片
优先使用仓库内相对路径。图片注明来源、作者/机构、日期、授权状态和必要的替代文本。不得引用本地绝对路径。

## 5. 状态
草稿、建设中、待验证、待审核、已确认、已归档。状态应反映证据与审核进度，不代表内容权威性。

## 6. 修改
保留有研究价值的旧结论和证据轨迹；修订时说明变更原因及影响范围。
