# 04｜设计案例研究

## 一、研究目的

本目录用于收集和分析格式塔视觉组织原则在真实设计作品中的应用。研究对象包括信息图形、编辑设计、海报、品牌视觉、图形符号、网页与界面、展览与导视、包装与产品视觉设计。

## 二、案例分析结构

### 01 基础信息
- 案例名称、作者/设计机构、创作时间、应用领域。
- 原始图片与可访问来源链接。
- 作品背景与设计目标（有证据时填写；未知则标注未知）。

### 02 原则识别
- 涉及哪些格式塔原则？
- 哪一项是主要原则，哪些是辅助原则？
- 具体视觉证据是什么？
- 是否存在多个原则共同作用或互相冲突？

### 03 视觉结构分析
- 点、线、面、体如何组织？
- 元素之间的距离、方向、轮廓和连接如何建立？
- 色彩、形状、纹理和区域如何形成关联？
- 图形与背景如何分离？
- 视觉层级和阅读路径如何形成？

### 04 信息组织分析
- 信息如何分组？
- 阅读顺序如何建立？
- 视觉关系是否对应真实信息关系？
- 是否存在潜在误读或可访问性问题？

### 05 设计评价
- 原则使用是否准确？
- 视觉组织是否有助于信息识别？
- 是否存在过度设计或无依据关联？
- 哪些方法可以迁移到其他项目？

### 06 研究结论
总结该案例中值得学习的视觉组织方式，并区分作品事实、分析推断和待核实信息。

## 三、案例编号

采用 GESTALT-C001、GESTALT-C002、GESTALT-C003……

建议每个案例一份 Markdown 分析文档；原始图片放在案例图片子目录或按项目约定的图片目录中，文档通过相对路径引用。不得仅保存图片而不记录来源。

## 四、案例记录模板

- 案例名称、作者/机构、年份、来源、设计领域、原始图片。
- 主要原则、辅助原则、具体视觉证据。
- 元素组织、阅读路径、图形与背景、与真实信息关系的一致性。
- 设计优点、局限/误读风险、可迁移方法。
- 已证实的观察、分析推断、待核实事项。

## 五、重要原则

不能因为作品看起来整齐、简洁或美观，就直接判断其使用了某一项格式塔原则。必须指出具体视觉证据，并解释它如何影响群组、层级、图底或阅读路径。视觉上的群组关系不自动等于数据中的真实关系。
