## 分析约定

- 先描述具体视觉线索，再判断原则，不以风格印象代替证据。
- 区分知觉组织、信息本身的关系和设计者的表达意图。
- 案例允许多原则并存，需标注主要与辅助原则。
- 每项原则文档均记录理论定义、知觉机制、视觉表现、设计应用、信息图形应用、实践方法、误用边界与参考资料。
