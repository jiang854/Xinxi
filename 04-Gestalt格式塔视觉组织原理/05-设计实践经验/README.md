# 05｜设计实践经验

## 一、研究目的

本目录记录格式塔视觉组织原则在实际设计过程中的应用、实验和经验总结。与外部作品案例研究不同，本目录强调主动改变视觉变量，观察其对视觉组织和信息理解的影响。

## 二、实践研究类型

### 01 单一原则实验
分别研究邻近、相似、连续、闭合等原则在不同视觉条件下的表现。

### 02 多原则组合实验
研究原则之间如何相互强化或产生冲突，例如邻近+相似、邻近+共同区域、相似+统一连接、连续+共同命运、图底+闭合。

### 03 版式设计实验
将同一内容制作成不同版式，比较群组判断、阅读路径、层级识别和信息查找效率。

### 04 信息图形实验
将格式塔原则应用于统计图形、信息图形、视觉符号和视觉叙事。

### 05 识别与阅读测试
观察不同设计方案对信息识别、分类、阅读顺序和误读的影响。

## 三、实践记录规范

每次实验记录：实验编号、实验名称与研究目标、使用原则、原始设计和修改过程、改变的视觉变量、对照方案与测试任务、观察结果或测试数据、设计问题与局限、实践结论与可复用方法。

## 四、实验编号

采用 GESTALT-P001、GESTALT-P002、GESTALT-P003……

## 五、实践记录模板

- 研究目标
- 使用原则
- 设计假设
- 原始方案与对照方案
- 保持不变的变量与改变内容
- 测试任务与对象
- 观察结果/数据
- 问题与局限
- 实践结论
- 可迁移的方法

## 六、结论有效性分级

- **观察记录：** 实验中直接观察到的现象。
- **设计判断：** 设计师对视觉效果的评价。
- **测试结果：** 通过受众识别或阅读测试得到的结果。
- **方法总结：** 可在其他项目中尝试复用的经验。

不能将未经测试的个人设计感受描述为已经得到心理学实验验证的结论。记录样本量、受众背景、设备和测试条件，避免过度推广结论。
