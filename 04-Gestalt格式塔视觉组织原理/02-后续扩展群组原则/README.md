# 后续扩展群组原则

研究传统群组线索之外的共同时间变化、共同边界、元素连接与区域统一性。此处“后续扩展”是知识库的组织标签，不代表四项原则具有相同的提出年代或理论来源。

4. [统一连接原则](04-统一连接原则.md)

## 分析约定

- 同步强调时间上的同时变化；共同命运强调运动方向或变化趋势一致。
- 元素连接强调离散元素之间的明确连接；统一连接强调连续同质区域形成基本视觉单位。
- 共同区域依赖共享边界或容器；邻近依赖空间距离。
- 每项原则需以具体视觉证据支持判断。
