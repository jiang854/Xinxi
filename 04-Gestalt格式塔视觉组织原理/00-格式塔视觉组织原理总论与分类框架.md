## 一、格式塔理论的基本概念

### 1.1 Gestalt 的含义

Gestalt 是德语词汇，通常译为格式塔、完形或整体形态。格式塔心理学研究人类如何将视觉刺激组织为有意义的整体，以及局部元素之间的关系如何影响整体感知。

其核心观点是：**视觉整体不是孤立元素的简单相加，而是由元素之间的组织关系形成的知觉结构。**

格式塔心理学主要由 Max Wertheimer、Wolfgang Köhler 和 Kurt Koffka 等心理学家推动发展。Wertheimer 于1912年发表关于似动现象（Phi Phenomenon）的研究，通常被视为格式塔心理学发展的重要起点。

### 1.2 格式塔理论与视觉设计的关系

格式塔理论不是直接规定设计形式的操作手册，而是解释视觉系统如何组织信息的心理学理论。设计师可以利用视觉组织规律，影响观众如何识别主体、判断元素关系、划分群组、区分图形与背景、建立阅读顺序并理解复杂结构。

在本知识库中，格式塔原则被转化为可观察、可分析、可实践的设计研究框架，而不是仅作为视觉风格标签。

### 1.3 研究边界

格式塔原则描述的是知觉倾向，不是数据真实性规则。视觉上接近、相似、连接或同步的对象，不必然在现实数据中具有统计关系、因果关系或共同分类。设计分析必须区分：

- **知觉关系：** 观众可能如何把视觉元素组织在一起。
- **信息关系：** 数据或内容本身实际存在什么联系。
- **设计意图：** 设计者希望观众如何理解。
- **理解结果：** 观众是否真的按预期理解，必要时需要测试。

格式塔原则没有全球统一、固定且唯一的条目总数。不同心理学综述、教材和设计资料会按理论历史、知觉层级及应用范围采用不同清单。因此，本库的13项是**项目研究范围与组织方案**，不宣称它是格式塔理论的全部原则。

## 三、13项原则的核心问题

| 原则 | 核心知觉线索 | 设计中常见作用 |
|---|---|---|
| 邻近 | 空间距离 | 建立信息分组 |
| 相似 | 视觉属性相似 | 建立类别与系列 |
| 良好连续 | 路径、方向与轮廓延续 | 引导视线与阅读 |
| 闭合 | 不完整形态的补全 | 形成简化图形 |
| 共同命运 | 运动方向或变化一致 | 表达群体运动 |
| 对称 | 结构对应与对称关系 | 建立稳定组织 |
| 平行 | 方向平行 | 建立方向性群组 |
| 同步 | 同时发生的变化 | 暗示共同变化 |
| 共同区域 | 共同边界或容器 | 建立模块分组 |
| 元素连接 | 元素之间明确连接 | 表达关系与路径 |
| 统一连接 | 连续区域的视觉属性统一 | 形成基本视觉单位 |
| 图形与背景 | 主体/背景分离与边界归属 | 建立视觉主次 |
| Prägnanz | 良好、稳定、简洁的整体组织 | 优化整体结构 |

## 四、原则之间的关系

实际设计中，多种原则通常同时发挥作用。例如一个信息模块可能同时使用邻近（标题与说明靠近）、相似（同类数据采用相同编码）、共同区域（内容置于同一容器）以及图形—背景组织（模块从页面背景中突出）。

案例分析不得强制“一件作品只对应一个原则”。应记录：

1. 主要组织原则；
2. 辅助组织原则；
3. 多原则相互强化的地方；
4. 原则之间发生竞争或冲突的地方；
5. 视觉分组与真实信息关系是否一致。

特别注意以下概念区别：

- **共同命运与同步：** 共同命运强调运动方向或变化趋势的一致；同步强调变化在时间上的同时发生。
- **元素连接与统一连接：** 元素连接强调离散元素之间存在明确连接；统一连接强调连续区域因视觉属性统一而形成单位。
- **邻近与共同区域：** 邻近依赖距离；共同区域依赖共享的边界或容器。
- **图形—背景与群组：** 前者涉及视觉场的主体/背景分割；后者涉及元素如何被组织成群。
- **Prägnanz 与极简主义：** Prägnanz 是整体知觉组织倾向，不等于所有设计都必须极简。

## 五、与知识库其他模块的关系

### 01｜信息图形数据逻辑
研究信息对象之间是什么关系，例如编年、层级、编目、字母表与地理关系。Gestalt 研究这些信息关系如何被视觉感知。

### 02｜信息图形类型案例
研究整张作品采用什么视觉表现方式。Gestalt 研究这些表现形式中的元素如何形成视觉整体。

### 03｜统计图形分析
研究数据如何经过计算和映射转化为图形。Gestalt 研究统计图形中的标记、标签、图例、区域与背景如何被组织和识别。

### ISOTYPE-基础图形设计
研究图形符号如何标准化、重复使用和表达数量关系。Gestalt 研究这些符号如何通过视觉属性形成群组与整体。

## 六、统一案例分析规范

每个案例必须回答：

1. 案例名称、作者/机构、年份、来源及原始图片在哪里？
2. 涉及哪些原则？主要原则与辅助原则分别是什么？
3. 具体视觉证据是什么（距离、颜色、轮廓、方向、连接、边界、同步等）？
4. 这些线索如何影响群组、层级、图底或阅读路径？
5. 视觉关系是否准确对应真实信息关系？
6. 是否有其他原则强化或干扰该组织？
7. 是否存在误读、可读性或可访问性问题？
8. 可以迁移到其他设计项目中的方法是什么？

不能仅凭“看起来整齐、简洁或美观”就认定某原则存在；必须指出具体视觉证据。

## 七、统一设计实践规范

每项原则至少可以开展：
- 单一原则的基础示意实验；
- 同一内容的不同布局对照；
- 两项或多项原则的组合实验；
- 改变视觉变量后的识别比较；
- 实际信息图形中的应用测试。

记录时区分：
- **观察记录：** 直接看到的现象；
- **设计判断：** 设计师对视觉效果的评价；
- **测试结果：** 通过受众识别或阅读测试得到的结果；
- **方法总结：** 可尝试迁移到其他项目的经验。

未经测试的设计感受，不应写成已经得到心理学实验验证的结论。
