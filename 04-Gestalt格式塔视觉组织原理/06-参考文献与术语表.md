## 二、术语表

| 英文 | 中文 | 本库使用说明 |
|---|---|---|
| Gestalt | 格式塔／完形 | 研究整体知觉组织的理论传统 |
| Perceptual Grouping | 知觉群组 | 将视觉元素组织为群组 |
| Proximity | 邻近／接近 | 由空间距离形成的分组线索 |
| Similarity | 相似 | 由视觉属性相似形成的分组线索 |
| Good Continuation | 良好连续 | 路径或轮廓的平滑延续 |
| Closure | 闭合 | 对不完整形态的知觉补全 |
| Common Fate | 共同命运 | 共同运动方向或变化趋势 |
| Symmetry | 对称 | 结构对应关系 |
| Parallelism | 平行 | 平行方向关系；其独立分类地位可能因来源而异 |
| Synchrony | 同步 | 时间上同时发生的变化 |
| Common Region | 共同区域 | 共享边界或容器形成的群组 |
| Element Connectedness | 元素连接 | 离散元素之间的明确连接 |
| Uniform Connectedness | 统一连接 | 连续同质区域形成基本视觉单位 |
| Figure-Ground | 图形与背景 | 主体/背景分割与边界归属 |
| Prägnanz | 简洁性／良好形态 | 形成良好、稳定整体的组织倾向 |

## 三、术语与分类说明

- Gestalt principles 的条目数量在不同资料中并不统一。
- 本仓库13项是项目工作分类，不是学术界唯一固定清单。
- Parallelism 在不同来源中可能作为独立群组线索，也可能并入其他组织规律；引用时应说明来源口径。
- Figure-Ground 是基础知觉组织机制，不应简单与普通群组原则并列为同一层级。
- Prägnanz 不等于极简主义，也不等于“越少越好”。
- Element Connectedness 与 Uniform Connectedness 必须区分：前者强调元素之间的连接，后者强调连续区域的视觉属性统一。
