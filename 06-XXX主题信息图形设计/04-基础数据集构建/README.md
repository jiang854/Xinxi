# 04｜基础数据集构建

## 阶段目标

将多来源资料转换为结构清晰、字段原子化、可检查、可追溯的基础数据集。

## 子文件夹

- [01-原始数据](01-原始数据/README.md)：保存未经修改的原始下载文件、摘录、拍摄记录和采集结果；原始文件只读保存，修改在副本中进行。
- [02-字段拆分与数据清洗](02-字段拆分与数据清洗/README.md)：拆分混合字段，统一日期、单位、名称、编码与缺失值；记录去重、纠错、转换和排除规则。
- [03-标准化基础数据集](03-标准化基础数据集/README.md)：保存可供后续叙事与设计使用的标准化表格；一列一种变量、一格一个原子值，必要时建立关联表。
- [04-字段字典与质量检查](04-字段字典与质量检查/README.md)：定义字段名称、含义、类型、单位、允许值、来源、缺失规则，并检查完整性、唯一性、一致性与异常值。

## 阶段交付物

原始数据备份、清洗记录、标准化基础数据集、字段字典、数据质量检查报告。

## 阶段完成检查

- [ ] 子文件夹中的材料已归档。
- [ ] 关键判断、数据来源和处理过程有记录。
- [ ] 未解决问题已列入项目总表。
- [ ] 已形成可交接给下一阶段的成果。
