## 用途

整合平面、照片、插画、手绘、3D或混合风格，形成标题、注释、标签、图例、卡片、连接线等组件规范。

## 阶段输出

将本子文件夹形成的材料整理为可追溯的文档、表格、图像或数据文件，并在上一级阶段 README 或项目总表中登记。

## 风格判断维度

- 媒介：照片、平面矢量、插画、手绘、3D、拼贴或混合。
- 视觉气质：编辑设计、档案感、科学说明、极简、复古、未来感等。
- 图形语言：几何形、轮廓线、纹理、符号、图标、地图标记。
- 信息层级：主标题、核心数据、辅助说明、来源注释。
- 一致性：不同页面/模块的字号、色彩、线宽、图标和间距规则。
