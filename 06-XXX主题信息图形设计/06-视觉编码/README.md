# 视觉编码

## 阶段目标

把数据、关系和叙事转化为一致、可读且有表现力的视觉系统，重点关注设计表达。

## 子文件夹

- [01-点线面体编码](01-点线面体编码/README.md)：确定点、线、面、体分别承载什么信息；记录形状、大小、方向、位置、纹理、层次与空间关系的编码规则。
- [02-色彩与材质系统](02-色彩与材质系统/README.md)：建立主色、辅助色、强调色、背景色和状态色规则；记录色彩语义、对比度、材质和印刷/屏幕适配。
- [03-文字排版与网格](03-文字排版与网格/README.md)：确定字体层级、字号、字重、行距、字距、段落宽度、对齐方式、网格系统和阅读节奏。
- [04-图像与图形系统](04-图像与图形系统/README.md)：规划摄影、插画、矢量图、地图、图标、纹理、装饰图形等视觉资产的风格、来源、裁切和使用规范。
- [05-统计图形与数据映射](05-统计图形与数据映射/README.md)：根据数据类型和叙事任务选择统计图形；记录字段映射到位置、长度、角度、面积、颜色等视觉通道的方式及图例。
- [06-ISOTYPE与符号系统](06-ISOTYPE与符号系统/README.md)：记录是否采用ISOTYPE或其他符号系统，定义图形单位、重复规则、比例、图例和可读性；不得把一般装饰图标直接等同于ISOTYPE。
- [07-视觉风格与组件规范](07-视觉风格与组件规范/README.md)：整合平面、照片、插画、手绘、3D或混合风格，形成标题、注释、标签、图例、卡片、连接线等组件规范。

## 阶段交付物

视觉编码矩阵、图形语法、色彩与字体规范、图像/符号系统、统计图形选型、视觉样张。
