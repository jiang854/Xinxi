# 01｜前期调研

## 阶段目标

建立选题依据，明确研究边界、目标受众和信息需求。

## 子文件夹

- [01-选题背景与核心问题](01-选题背景与核心问题/README.md)：记录主题背景、现实语境、选题动机、核心问题、研究范围与不纳入范围。
- [02-受众与使用场景](02-受众与使用场景/README.md)：明确目标受众、已有知识、阅读环境、使用场景，以及读者看完信息图后需要理解或完成的任务。
- [03-相关作品与案例调研](03-相关作品与案例调研/README.md)：收集同主题和相邻主题作品，分析其主题切入、信息结构、视觉风格、优点、局限与可借鉴方法。
- [04-研究资料与调研记录](04-研究资料与调研记录/README.md)：保存访谈、观察、网页、书籍、论文、报告和其他前期资料，记录作者、日期、链接、页码及可信度。

## 阶段交付物

调研摘要、核心问题定义、受众画像/任务、参考案例清单、资料来源记录。

## 阶段完成检查

- [ ] 子文件夹中的材料已归档。
- [ ] 关键判断、数据来源和处理过程有记录。
- [ ] 未解决问题已列入项目总表。
- [ ] 已形成可交接给下一阶段的成果。
