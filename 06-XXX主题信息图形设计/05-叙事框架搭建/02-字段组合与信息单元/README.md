# 02-字段组合与信息单元

## 用途

记录哪些基础字段组合成一个信息单元，说明组合逻辑、所表达的含义、所需数据和输出形式。

## 建议记录

- 本项工作要回答的问题：
- 使用的资料/数据：
- 分析过程与判断依据：
- 关键发现：
- 尚未解决的问题：
- 文件来源、日期与版本：

## 阶段输出

将本子文件夹形成的材料整理为可追溯的文档、表格、图像或数据文件，并在上一级阶段 README 或项目总表中登记。

## 字段组合示例

| 字段组合 | 形成的信息单元 | 可支持的叙事/表达 |
|---|---|---|
| 名称 + 纬度 + 经度 | 地点实体 | 地图上的地点分布 |
| 地区名称 + GDP数值 + 年份 | 地区年度指标 | 地区经济比较或变化 |
| 人物名称 + 出生日期 + 关键事件 | 人物与事件 | 人物生平时间线 |
| 对象名称 + 类别 + 材料 + 图像路径 | 对象档案 | 分类目录、图鉴 |
| 关键词 + 词频 | 词项及权重 | 词云或关键词排序 |

每个信息单元须注明字段来源、组合条件、单位/口径、缺失处理和它要回答的问题。字段组合是叙事设计，不应制造原始数据并不支持的因果关系。
