## 研究原则

1. **案例先行，归纳原则。** 具体设计原则以案例证据为依据，通用理论作为分析框架。
2. **区分分类维度。** 数据类型、数据架构逻辑、视觉表现类型和基础图表是不同层次，不能互相替代。
3. **区分事实、推断与设计建议。** 无法从案例确认的数据来源、计算方式或设计意图标注“待核实”。
4. **结构先于风格。** 先确定数据关系、信息层级和阅读路径，再决定装饰和视觉风格。
5. **图片单份存储。** 案例图按主视觉表现类型归档，数据架构和辅助表现作为索引标签，不重复保存。

## 新案例的统一处理流程

1. 记录案例来源、作者/机构、年份和原图位置。
2. 识别数据类型和信息对象。
3. 判断主数据架构逻辑。
4. 判断主视觉表现类型和辅助表现。
5. 拆解图表方法、视觉编码、信息架构和叙事结构。
6. 记录事实、推断、可迁移方法和局限。
7. 将原图只存入一个主目录，并在索引中交叉标注。
8. 多个案例反复支持某项规律后，再更新理论文档。

## 证据与版本约定

- **案例观察**：能从原图或来源材料直接确认的事实。
- **分析推断**：根据视觉线索推测的数据结构或设计意图。
- **归纳原则**：由多个案例反复支持的可迁移方法。
- **待核实**：课件没有提供足够证据的信息。

当前版本以三份课程资料为基础建立知识框架；后续新增案例将按同一套分类与分析流程持续迭代。
