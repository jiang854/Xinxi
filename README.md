# 信息图形类型学研究知识库

本仓库以用户提供的《第三讲—信息图形类型学.pdf》（73页，2026-11-19）为基础理论资料，并以实际案例检验与修订概念、数据逻辑、视觉编码与叙事方法。

## 分类体系：数据逻辑与视觉表现

- **五大数据架构逻辑**（课程第2—21页）：编年型、层级型、编目型、字母表型、地理图型。分析一个作品以什么关系组织信息。
- **常用视觉表现类型**（课程第22—38页）：混合型、文字/列表型、时间轴型、示意图型、流程图型、比较型、地标型及其他。分析以什么视觉语言传达信息。两种分类相互交叉，不是一一对应。
- **统计图形分析**：独立研究图表的数据输入、统计计算、布局算法与视觉编码。它是图表技术层，不是整张信息图形的表现类型。
- **ISOTYPE-基础图形设计**：横向基础图形设计方法，不是信息图形类型，也不是统计图形类别。

## C001 案例结论

新闻版面《A live in death》（South China Morning Post，2025-01-02）以材料准备→塑形→制作部件→烧制→上色为叙事骨架。若必须映射课程规定的五大类，可归为广义编年型（不可逆顺序），但准确的核心关系是工序依赖。在表现分类上以 Process / How-to 为主，混合人物手绘、局部操作、标注数字及辅助定位地图，不是严格的 Timeline 时间刻度图。

## 持续维护约定

1. 用户提供案例图→识别主题、对象、字段、相互关系与证据。
2. 分别判断主/辅助数据逻辑与主/辅助表现类型。
3. 若作品包含统计图形，再拆解数据字段、聚合口径、计算方式、视觉编码、图例与误读风险；若没有量化统计图形，允许明确写“无独立统计图形”。
4. 将案例事实、分析推断、待核实信息分别标注。先写02目录，之后以案例反哺01；统计图形机制补充至03。
5. 课件是理论来源，不等于所有定义都无歧义；例如编目型英文称法、字母表型案例外延及层级型课件文字描述的差异，须注明并保留核验空间。
6. 不要把 ISOTYPE 图像统计法误称为 ISO 标准符号；不要把装饰当数据编码。
7. RAWGraphs 是技术样本，不是唯一标准；软件默认聚合方式不自动等于某个案例的真实统计口径。
