# 案例库｜逐个案例分析文档

本目录集中存放逐个信息图形作品的案例分析文档，与“案例图”中的原图文件分开管理。

## 文档索引

- [C001｜兵马俑制作工艺信息图：从陶土到成品](C001-兵马俑制作工艺信息图.md)

## 编号规则

采用 C001、C002、C003……连续编号。每个案例一份 Markdown 文档；原图统一放入上一级“案例图”目录，并在案例分析文档中使用相对路径引用。

## 分析规范

每份文档记录案例基本信息、证据状态、主/辅助数据逻辑、主/辅助表现类型、统计图形、视觉编码、信息架构、视觉叙事、分类理由、可迁移方法、误读风险和待核实问题。

分析中区分可见事实、课程理论、分析推断与待核实信息；不因视觉相似而擅自推定数据关系。
