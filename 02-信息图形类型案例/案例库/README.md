## 三、文档归档规则

- 本目录共归档21份 Markdown 文档：20份类型说明 + 1份案例分析。
- 类型说明以01—20编号；具体案例分析采用C001、C002、C003……编号。
- 原图不嵌入或重复存放在 Markdown 文档中，统一放入上一级“案例图”目录，并在案例分析文档中使用相对路径引用。
- 案例分析记录案例基本信息、证据状态、主/辅助数据逻辑、主/辅助表现类型、统计图形、视觉编码、信息架构、视觉叙事、分类理由、可迁移方法、误读风险和待核实问题。
- 分析中区分可见事实、课程理论、分析推断与待核实信息；不因视觉相似而擅自推定数据关系。
