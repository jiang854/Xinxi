# 02｜信息图形类型案例

本模块管理信息图形表现类型、案例原图、逐案分析和分类索引。案例以独立文件夹归档，类型说明与案例资产分离。

## 1. 分类边界
数据逻辑描述信息关系；表现类型描述画面组织方式；基础设计方法描述可复用的视觉表达手段。三者允许交叉，不互相替代。

## 2. 类型目录
20 种类型分别位于 01—20 类型目录中，每个目录包含 00-标签说明.md 和 案例/README.md。具体案例按主表现类型归档。
