# 01 混合型信息图形案例图片

本目录仅存放归类为 **01-混合型信息图形（Mixed Charts）** 的案例原图、局部图和分析辅助图。

## 文件命名

建议格式：`M001-主题关键词-来源或作者-original.png`

- M001、M002……为本类型内部连续编号。
- 原图保留 `original` 标记；分析标注图另存为 `annotated`。
- 记录案例来源、作者/机构、原始链接和获取日期（已知时填写）。

## 入库规则

1. 本目录对应案例说明文档：[01-混合型信息图形](../../01-混合型信息图形（Mixed%20Charts）.md)。
2. 每个案例在对应 Markdown 文档中登记编号、图片路径、来源、分析结论。
3. 混合型强调统计图形与符号/插画等多种视觉语法的协同；归类时需说明各图形元素承担的信息功能。
4. 同一案例如兼具其他类型，图片只在主类型目录保存一次，在其他文档中交叉链接，不重复存储。
