课程案例缩略总览：[查看总览图](../课程案例图像分类总览.jpg)。页码与辅助类型见[案例图像分类索引](../../../../06-案例图像分类索引.md)。

## 文件命名

建议格式：`M001-主题关键词-来源-P22-original.png`

- M001、M002……为本类型内部连续编号。
- 原图保留 original 标记；分析标注图另存 annotated。
- 不确定的作者、年份和原始来源标记“待核实”。

## 入库规则

1. 对应说明文档：[01-混合型信息图形](../../01-混合型信息图形（Mixed%20Charts）.md)。
2. 混合型强调多种视觉语法之间存在明确的信息分工。
3. 归类时说明统计图、图标、插画、地图和文字各自承担什么信息功能。
4. 同一案例只在主类型目录保存一次；辅助类型通过相对链接引用。
