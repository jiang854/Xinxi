# 13-视觉简历型

视觉简历（Visual Resume）案例。以视觉模块呈现个人经历、能力和成果。课程来源：第三讲 PDF 第34页。

## 命名规则

使用 `RES-001-主题关键词-L讲次-P页码.jpg` 格式连续编号。保留原图，不覆盖；标注版另存 annotated 版本。

## 案例记录要求

每张图片登记原始 PDF、PDF 页码、案例名称、主数据架构、辅助表现、图表方法、视觉编码、信息架构和待核实项。原图只存放在一个主目录，交叉类型写入索引。
