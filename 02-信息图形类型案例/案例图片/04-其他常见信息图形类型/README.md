# 04 其他常见信息图形类型案例

本目录用于归档第三讲第 25—38 页及第二讲第 11—13、30—31 页中的其他视觉表现案例。当前案例原图仍嵌入课程 PDF，本目录先建立分类与页码导航；逐张导出原图时，沿用案例编号规则保存到本目录下对应类型子文件夹。

## 案例分类与来源

| 类型 | 来源 PDF 页码 | 课件中展示的案例 |
|---|---|---|
| 示意图型（How-to） | 第三讲 p25 | 三明治分解/制作示意 |
| 流程图型（Process） | 第三讲 p26 | 创作过程与路径图 |
| 比较型（Comparison） | 第三讲 p27；第二讲 p11—13 | 人物与指标比较；巴西各区域失业率图 |
| 地标型（Location） | 第三讲 p28 | 区域位置与路线信息 |
| 图片式（Photo-graphic） | 第三讲 p29 | 摄影图像叠加数据标注 |
| 层级型（Hierarchical） | 第三讲 p30 | 芬兰熊类分布与卷轴式结构 |
| 单一图表型（Single Chart） | 第三讲 p31；第一讲 p15—17 | 单一主图表；Playfair 统计图与南丁格尔玫瑰图 |
| 视觉化文本（Visualized Text） | 第三讲 p32 | 文字本身作为视觉结构 |
| 解剖型（Anatomical） | 第三讲 p33 | 对象内部结构说明 |
| 视觉简历（Visual Resume） | 第三讲 p34 | 个人经历与能力信息组织 |

| 编年 + 编目混合型 | 第三讲 p36—37 | 时间与分类两种逻辑结合 |
| 3D 信息图形 | 第三讲 p38 | 三维空间表达 |
| 混合型/交互型 | 第二讲 p30—31 | 电商销售综合分析；COVID-19 仪表板 |

## 归档规则

1. 每个案例确定一个主表现类型，并记录辅助表现与主数据架构。
2. 原图只保存一次；其他分类使用相对链接交叉引用。
3. 文件命名采用“类型缩写 + 三位序号 + 主题 + 来源页码”。
4. 图片文件保留原始比例，不覆盖原图。
5. 课件未提供作者或原始来源时标记“待核实”。
6. 详细页码与分类解释见[06-案例图像分类索引](../../../../06-案例图像分类索引.md)。
