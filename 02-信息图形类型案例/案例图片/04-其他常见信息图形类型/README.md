## 归档原则

1. 先确定案例的主视觉表现类型，再决定存放目录。
2. 数据架构作为辅助标签，不重复保存同一张图。
3. 文件名使用类型缩写、三位编号、主题和讲次页码。
4. 图像保留原始比例，原图不覆盖；标注版另存。
5. 不确定的作者、年份、数据来源或计算方式标记“待核实”。
6. 详细页码与分类依据见[06-案例图像分类索引](../../../../06-案例图像分类索引.md)。
