# 04-示意图型

示意图型（How-to）案例。主要表达对象构成、部件关系或操作方法。课程来源：第三讲 PDF 第25页。

## 命名规则

使用 `HOW-001-主题关键词-L讲次-P页码.jpg` 格式连续编号。保留原图，不覆盖；标注版另存 annotated 版本。

## 案例记录要求

每张图片登记原始 PDF、PDF 页码、案例名称、主数据架构、辅助表现、图表方法、视觉编码、信息架构和待核实项。原图只存放在一个主目录，交叉类型写入索引。
