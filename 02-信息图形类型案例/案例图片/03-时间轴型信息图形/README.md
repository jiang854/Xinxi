# 03 时间轴型信息图形案例图片

本目录用于归档以时间轴作为主要视觉骨架的信息图形案例。

## 课程来源案例

- 第三讲 PDF 第 24 页：包豪斯相关人物与建筑作品环形时间轴。
- 第三讲 PDF 第 3—5 页：螺旋式、杂志版和路径式编年案例。
- 第一讲 PDF 第 25 页：20 世纪西方艺术流派发展图。

课程案例缩略总览：[查看总览图](../课程案例图像分类总览.jpg)。页码与辅助类型见[案例图像分类索引](../../../../06-案例图像分类索引.md)。

## 文件命名

建议格式：`T001-主题关键词-来源-P24-original.png`

- T001、T002……为本类型内部连续编号。
- 原图保留 original 标记；分析标注图另存 annotated。
- 不确定的作者、年份和原始来源标记“待核实”。

## 入库规则

1. 对应说明文档：[03-时间轴型信息图形](../../03-时间轴型信息图形（Timeline%20Infographics）.md)。
2. 记录时间范围、时间精度、时间轴形式，以及刻度是否按真实比例排列。
3. 节点表示事件，条带可表示持续时间，刻度表达时间尺度。
4. 时间先后不自动代表因果关系。
5. 同一案例只在主类型目录保存一次；辅助类型通过相对链接引用。
