# 02 文字型/列表型信息图形（Informational / List Infographics）

> 课程案例索引：第三讲 PDF 第 23 页；视觉化文本见第 32 页。请结合[案例图像分类索引](../../06-案例图像分类索引.md)查看来源页码。

## 1. 概念定义

文字型/列表型信息图形以文字信息、条目集合和可扫描的组织结构为主要内容，通过标题、短句、编号、项目符号、图标、色块、分栏和信息卡片，将知识、步骤、事实、建议或对象清单组织为易于浏览和记忆的视觉内容。

它不是把普通文字简单排进版面。关键在于文字经过筛选、压缩、分组和层级化，并通过视觉编码建立阅读路径。列表型强调多个并列条目；文字型范围更广，还可能包含解释段落、知识卡片和步骤说明。

## 2. 基本信息逻辑

常见信息单元：标题、导语、条目、分类标签、编号/顺序、解释/例证、来源/注释。

常见组织逻辑：并列罗列、分类列表、顺序列表、按明确标准排序的列表、对照列表、问答或知识卡片。编号不一定代表排名或重要性，需结合案例判断。

## 3. 统计图形与计算方式

通常以信息组织为主，不一定使用统计图表。可结合图标阵列、对照表、流程图、比例条、小型柱状图/点图和关键数字强调。若出现数量、排名或百分比，应记录来源、计算口径和统计范围。

## 4. 视觉编码方法

- 点、图标与编号：图标识别条目主题；编号建立顺序和定位。
- 线与分隔：分隔线帮助区分模块；箭头仅用于真实步骤、流程或关系。
- 面与版式：色块、卡片、边框和留白建立分区；网格适合并列条目，单列适合顺序阅读。
- 色彩与文字：颜色区分类别或模块；标题、关键词、正文、注释建立层级。

## 5. 数据/信息架构

先确定列表组织依据：条目是否并列、是否分类、是否有顺序、是否需要比较、是否有优先级、是否需要索引。常见结构为标题—导语—分类标题—条目列表—补充说明；核心数字—解释模块—来源注释；步骤总览—分步说明—注意事项。

## 6. 视觉叙事架构

常见方式：总览式、扫描式、顺序式、对照式和卡片式。设计时明确读者最先看到什么、每个条目需读到什么程度，以及哪些内容可以略读。
