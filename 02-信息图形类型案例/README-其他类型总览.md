## 统一归档规则

1. 每张案例图确定一个主视觉表现类型，原图只存放一份。
2. 数据架构、辅助表现和主题领域作为标签记录，不重复保存图片。
3. 文件名采用“类型缩写 + 三位编号 + 主题关键词 + 来源”。
4. 原图不覆盖；裁切图、分析标注图另存。
5. 尽量记录来源、作者/机构、年份和原始链接；未知信息标注“待核实”。
6. 归类依据是主要信息关系和读者任务，不是单纯的配色或装饰风格。
7. 案例分析应区分可见事实、分析推断和可迁移方法。
