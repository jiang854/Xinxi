# 17 词云信息图

本目录用于存放以词语或短语为视觉主体，通过文字大小、字重、颜色、方向和空间布局呈现关键词集合的词云图型案例。

## 类型识别

词云图型通常用于展示文本语料中的高频词、核心主题词或经过特定权重计算的关键词。词语本身既是信息内容，也是主要视觉元素。

归类时需要确认：
- 词语来自什么文本、语料或关键词集合；
- 词频或权重如何计算，是否经过归一化；
- 字号、字重、颜色等视觉变量分别编码什么；
- 是否进行了停用词过滤、同义词合并、词形归一或人工筛选；
- 词语布局是按权重排列，还是仅为填充画面而自动排布。

## 视觉编码分析

| 视觉变量 | 可能承担的作用 | 分析注意事项 |
|---|---|---|
| 字号/文字面积 | 词频或权重 | 需要说明映射依据；面积感知不等于精确数值读取 |
| 字重 | 强调程度或层级 | 不应与字号编码产生冲突 |
| 色彩 | 主题分类、情感类别或视觉分组 | 若颜色没有数据含义，应标记为装饰性编码 |
| 方向/旋转 | 版面节奏和空间适配 | 通常不代表词语之间的关系 |
| 位置/分组 | 主题聚类或版面组织 | 只有存在明确布局规则时，才能解释为语义邻近或类别关系 |
| 字体 | 语气、风格和可读性 | 不宜因装饰字体降低辨识度 |

## 案例记录要求

每个案例尽量记录：
1. 案例编号、名称、来源、作者/机构、原始链接及获取日期。
2. 文本来源、语料范围、时间范围和样本规模。
3. 词语提取方式、分词方法、停用词处理和同义词归并规则。
4. 词频或权重计算方法；无法确认时标记“待核实”。
5. 字号、颜色、字重、方向和位置的编码含义。
6. 是否存在主题聚类、语义关系或仅为自由排布。
7. 阅读重点、信息优势、局限和可迁移的设计方法。

## 文件命名

建议格式：`WCL-001-主题关键词-来源-original.png`

- WCL-001、WCL-002……为本类型连续编号。
- 原始图片保留 original；裁切图和分析标注图分别使用 cropped、annotated。
- 不覆盖原图；来源不明时标记“来源待确认”。

## 归档原则

词云可以同时具有混合型、文字型或编目型特征。此目录以“词云作为主要视觉表现”为主类型；其他信息架构作为辅助标签记录。同一张案例图只保存一份，其他分类文档通过链接交叉引用。

> 当前类型说明先建立分类与分析规范。后续收到词云案例图后，将原图放入对应 CASE 案例文件夹，再依据实际案例补充具体分析，不预设未被案例支持的设计结论。
