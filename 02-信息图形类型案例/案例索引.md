## 三、归档与编号规则

1. CASE 编号在全库唯一、连续分配，不因主表现类型变化而重编号。
2. 每个案例以主要视觉表现和读者任务确定唯一主归属。
3. 辅助表现、数据逻辑（编年、层级、编目、字母索引、地理等）与基础设计方法写入案例 README 和本索引。
4. 原图、裁切图、标注图、数据集和数据字典归入对应 CASE 文件夹；原图不得覆盖，来源和授权状态需单独记录。
5. 缺失图片、原始数据、来源或授权时如实标记，不以推测填补。
6. CASE-0001 的历史编号 C001、CASE-0002 与 CASE-0003 的来源仓库编号均保留在历史编号列，避免编号冲突导致追溯中断。
