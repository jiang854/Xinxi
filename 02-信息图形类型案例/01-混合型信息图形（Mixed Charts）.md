# 01 混合型信息图形（Mixed Charts）

> 状态：类型说明初稿；具体原则以用户提供的案例图分析为依据。当前尚无案例图，因此以下属于分析框架和待验证假设。

## 1. 概念定义

混合型信息图形将两种或多种信息表达方式组合在同一叙事系统中，例如统计图形、图标、象形符号、示意图、地图、流程、插画、文字说明和标准化图形符号。它不仅呈现数据，还通过视觉编码和叙事结构，将数据关系转化为易于理解的视觉信息。

它不同于仅把多个统计图表并排放置的数据可视化。混合型信息图形通常具有更明确的主题叙事、信息层级、符号语义和阅读路径。统计图形是表达工具之一，而不是全部内容。

## 2. 与数据可视化的关系

- 数据可视化侧重将数据变量映射为视觉变量，支持比较、识别模式、分析或探索。
- 混合型信息图形在数据映射之外，进一步组织故事、情境、解释、图标语义和阅读节奏。
- 两者都可能使用统计图表、比例、坐标、颜色和数据标签。
- 是否存在明确的信息叙事、图形符号系统、解释性内容与视觉层级，是判断其信息图形属性的重要线索。

不能仅凭“使用插画”就认定为混合型；应确认插画或符号是否承担信息编码或叙事功能。

## 3. 基本构成与数据逻辑

混合型没有单一固定的数据结构，常见构成包括量化数据、分类数据、对象数据、关系数据和叙事信息。设计前应建立信息—图形映射：每项重要信息由什么视觉元素表达？该元素表达类别、数量、方向、位置还是情境？装饰元素与数据编码元素应明确区分。

## 4. 统计图形与计算方式

| 图形/方法 | 主要表达 | 适用条件 |
|---|---|---|
| 柱状图 | 类别间数值比较 | 类别清晰、量纲一致 |
| 折线图 | 连续时间变化 | 时间顺序明确 |
| 饼图/环形图 | 整体组成比例 | 类别较少且总和有意义 |
| 堆叠图 | 多类别构成变化 | 组成关系明确 |
| 散点图 | 两个数值变量关系 | 需要观察分布 |
| 气泡图 | 多维量化信息 | 尺寸图例清晰 |
| 图标阵列 | 数量或比例 | 单位图标代表值明确 |
| 比例符号 | 对象数量差异 | 符号大小规则明确 |
| 地图 | 位置、区域差异、空间流动 | 地理单元和口径明确 |

可能涉及总量、占比、差值、变化率、均值、中位数、密度和标准化指标。不同量纲不可直接叠加；比例必须交代分母；图标数量、面积与数值之间应有明确换算。坐标轴、单位、时间窗口和图例不能因装饰化而丢失。

## 5. 视觉编码方法

### 点与符号
统计点、数据标记和图标可以组合，但需区分数据标记与装饰图标。自定义象形符号应建立稳定语义映射。ISO 7001 公共信息符号、ISO 7010 安全标志等，只有确实采用对应标准图形时才能标注为 ISO 符号；原创或风格化图标不能未经核验称为标准符号。

### 线
坐标轴、趋势线、流程线和关系连线承担明确功能。线宽可表达流量或关系强度，但需图例；装饰线不得与数据线混淆。

### 面与体
面积、色块和容器形状可表达比例、分类、范围或组成。立体图形可用于场景化表达，但若体积代表数据，必须明确比例规则。插画与统计图形融合时，图表仍应可读、可比较。

### 色彩
色彩可区分类别、标记重点、建立叙事分区或编码数值。同一颜色尽量保持同一语义；连续数据使用有序色带，类别使用区分色，重点色应有限。

### 文字与版式
标题提出核心问题，导语提供背景，数据标签解释数值，注释交代口径。通过字号、字重、对齐、留白和分栏建立阅读顺序，并保证单位、来源和结论可被找到。

## 6. 数据/信息架构

常见模式：
1. 中心主题 + 周边模块。
2. 总览 + 分析模块。
3. 流程/路径 + 数据节点。
4. 地图 + 统计图表。
5. 对象插画 + 数据注释。
6. 多模块围绕同一主题的拼接结构。

每个模块应有清晰职责，避免重复表达同一信息或拼接无关数据。

## 7. 视觉叙事架构

可采用引入 → 概览 → 展开 → 关联 → 解释 → 收束的路径。实际阅读可以线性、模块化或自由浏览，应通过编号、色彩、方向、空间分组和标题层级提示读者。

## 9. 当前待验证假设

- 混合型的关键是多种视觉语法之间存在明确的信息分工。
- 统计图形提供量化依据，符号/插画提供对象识别、情境或类别线索。
- 视觉叙事将分散模块组织成整体理解路径。
- 视觉统一不等于所有图形风格相同，更重要的是符号语义、比例规则和信息层级一致。
