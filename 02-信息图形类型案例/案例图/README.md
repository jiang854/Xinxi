# 案例图｜信息图形原图集中存放区

本目录统一存放信息图形案例原图、裁切图和分析标注图。按扁平化方式管理，不再按信息图形类型建立子文件夹。

## 文件命名

建议格式：`类型缩写-三位编号-主题关键词-来源-original.png`

- 混合型：M001、M002……
- 文字/列表型：L001、L002……
- 时间轴型：T001、T002……
- 其他类型：沿用各类型说明文档中的缩写。
- 原图使用 original；裁切图使用 cropped；分析标注图使用 annotated。

## 归档规则

1. 一张案例原图只保存一份，避免不同类型目录重复存储。
2. 交叉类型在案例索引或案例分析文档中标注，不复制图片。
3. 尽量记录原始来源、作者/机构、年份、课程讲次与页码。
4. 不覆盖原图；分析标注另存。
5. 文件名与案例分析编号建立对应关系。
