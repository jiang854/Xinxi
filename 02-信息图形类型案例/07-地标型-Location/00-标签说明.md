# 07 地标型信息图形

地标型（Location）案例。主要表达地点、路线、地标和空间导航。课程来源：第三讲 PDF 第9、17—21、28页；第一讲 PDF 第4、14、18、28页；第二讲 PDF 第10页。

## 命名规则

使用 `LOC-001-主题关键词-L讲次-P页码.jpg` 格式连续编号。保留原图，不覆盖；标注版另存 annotated 版本。

## 案例记录要求

每张图片登记原始 PDF、PDF 页码、案例名称、主数据架构、辅助表现、图表方法、视觉编码、信息架构和待核实项。原图与派生图只存放在该 CASE 文件夹中，交叉类型写入全库索引。

## 地理逻辑与视觉表现的边界

本目录归档以地点、地标、路线或空间导航作为主要视觉组织形式的案例。地理型首先是数据逻辑：位置、区域、邻接、距离、分布与流动描述信息对象的空间关系；当地图、地标或空间导航成为画面主要表现方式时，归入本目录。旧“地理型”独立目录的识别要点并入本说明，不再另设第19类文件夹。地图与统计图、文字或插画组合时，可在全库[案例索引](../案例索引.md)标注辅助表现类型。
