# 04｜设计实践

本目录用于记录 ISOTYPE 方法在实际信息设计中的实验、制作、测试与迭代。实践过程应可复现，并与数据来源及符号规范相互对应。

## 实践流程

1. **问题与受众**：定义传播问题、目标读者和阅读场景。
2. **数据整理**：明确对象、统计单位、总体范围、时间范围和数据来源。
3. **符号草拟**：为对象设计可辨识的图符，形成初步符号清单。
4. **系统规范**：统一视角、比例、线条、色彩、变体和组合规则。
5. **数量映射**：制定图符单位、重复阵列、分数符号和舍入规则。
6. **版式编排**：组织分组、阅读顺序、标题、图例和注释。
7. **理解测试**：检查符号识别、数量解读、比较准确性和阅读负担。
8. **迭代归档**：记录反馈、修订理由、最终规范和文件版本。

## 每次实践建议记录

| 字段 | 内容 |
|---|---|
| 实践编号 / 名称 | 唯一编号与简明名称 |
| 设计问题 | 希望解释或比较什么 |
| 受众与场景 | 目标读者、媒介、尺寸与使用环境 |
| 数据来源 | 原始数据、口径、时间与许可 |
| 符号对象 | 图符所代表的对象及语义 |
| 视觉规范 | 造型、比例、颜色、变体与组合 |
| 数量规则 | 单位、重复、部分符号、舍入与图例 |
| 测试方法 | 识别、解读、比较或可读性测试 |
| 结果与修订 | 发现的问题、调整内容和原因 |
| 版本与日期 | 文件版本、修改日期与负责人 |

## 评价重点

- 符号是否容易识别且语义稳定？
- 数量单位是否直观、准确且可比较？
- 图像是否真正承担数据表达，而非仅作装饰？
- 图例和注释能否支持独立阅读？
- 设计在缩小、黑白打印和不同媒介中是否可读？
- 受众测试是否揭示误读、遗漏或不必要的认知负担？
