# 01｜历史与文献

本目录用于研究 ISOTYPE 的历史背景、形成过程、发展脉络、相关人物与机构，以及原始文献和后续学术研究。

## 研究内容

- 历史背景与社会传播语境
- ISOTYPE 的形成、组织实践与发展阶段
- 相关人物、团队、机构及其分工
- 图像统计、视觉教育与公众传播之间的关系
- 原始出版物、档案、展览和二手研究

## 文献记录字段

| 字段 | 记录要求 |
|---|---|
| 文献编号 | 全目录唯一编号 |
| 作者 / 机构 | 按原始出版物著录 |
| 标题 | 保留原文标题，必要时附译名 |
| 年份 | 出版年或档案形成时间；未知则标注待核实 |
| 文献类型 | 原始出版物、论文、专著、档案、展览资料等 |
| 出版 / 收藏信息 | 出版社、期刊、档案馆或收藏机构 |
| 原始链接 | 优先官方馆藏、出版机构或作者页面 |
| 研究主题 | 历史、理论、图符、数量表达、传播等 |
| 核验状态 | 已核验、部分核验、待核实 |

## 资料使用原则

1. 区分原始文献和后来的研究阐释。
2. 直接引述应记录页码或档案定位信息。
3. 不根据二手网页的简短介绍推断未经核验的历史细节。
4. 同一文献的不同版本分别记录，说明版本差异。
5. 暂无可核验资料时保留研究问题，不虚构书目或时间线。

## 推荐工作顺序

先建立文献清单，再整理时间线与人物/机构关系，最后将有文献支持的历史结论回写到 [00-ISOTYPE概念与方法](../00-ISOTYPE概念与方法.md)。
