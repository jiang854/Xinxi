# ISOTYPE概念与方法

> **标签属性：基础图形设计方法 / 视觉表达方法**
>
> **分类边界：ISOTYPE 不是一种信息图形表现类型。** 它是一套以标准化、可重复的象形图像符号组织和传达社会统计信息的方法，可与地理型、比较型、混合型、时间轴型等表现形式交叉使用。

## 1. 概念定位

ISOTYPE（International System of TYpographic Picture Education，国际图像教育系统）是一种以标准化、可重复的象形图像符号组织和传达社会统计信息的视觉方法。其核心不是单纯“把文字换成图标”，而是建立一套一致、可学习、可比较的图像符号语法，使复杂的社会事实和数量关系更容易被公众理解。

本知识库将 ISOTYPE 定位为**基础图形设计方法**：它可以服务于不同的数据架构和画面表现类型，而不是独立的内容分类或版式类型。

## 2. 核心设计原则

1. **图像符号承担信息意义**：符号应代表明确的人、物、群体或统计对象，而非纯装饰。
2. **符号系统保持一致**：同一作品中的符号在造型、比例、视角和语义上应具有稳定规则。
3. **数量表达规则明确**：若以重复图像表示数量，应说明一个符号代表多少对象；必要时使用分数符号、部分符号或明确图例。
4. **可比较、可读懂**：读者能够识别符号代表什么，并理解不同符号数量或组合之间的差异。
5. **图像与数据相互对应**：图像不是给数字配插画，而是参与表达数据对象、数量或分类关系。
6. **面向公众传播**：通过简化、标准化和视觉重复降低理解门槛，但不能牺牲数据准确性。

## 3. 与一般图标、插画及 ISO 标准符号的区别

| 视觉形式 | 主要作用 | 是否可直接标记为 ISOTYPE |
|---|---|---|
| 装饰性图标 | 美化版面、营造气氛 | 否 |
| 功能性图标 | 指示操作、方向或类别 | 通常否 |
| 普通信息插画 | 解释对象、场景或过程 | 不一定 |
| 重复象形符号表达数量 | 用统一图像单位呈现统计数量 | 具备 ISOTYPE 特征，仍需检查符号系统与数量规则 |
| ISOTYPE 式图像统计系统 | 以标准化图像符号系统组织社会统计信息 | 可以标记 |
| ISO 标准图形符号 | 依据 ISO 标准定义的公共信息或安全符号 | 不等于 ISOTYPE |

**特别注意：ISOTYPE 与 ISO 是不同概念。** ISOTYPE 不是“ISO 图标”的简称，也不意味着使用了 ISO 7001、ISO 7010 等标准符号。不能因为作品出现统一风格的图标，就称其为 ISOTYPE。

## 4. 方法流程

1. **确定传播问题**：明确作品希望公众理解的社会事实、对象和比较关系。
2. **定义统计对象**：确认一个数据记录代表什么，统计单位、总体范围、时间范围和来源是什么。
3. **建立符号清单**：为每类对象设计可辨识的图像符号，并记录名称、语义和适用范围。
4. **制定符号语法**：统一造型风格、视角、比例、轮廓、细节密度和变体规则。
5. **定义数量映射**：明确一个完整符号代表的数量、是否允许部分符号、如何处理余数和舍入。
6. **组织图像阵列**：通过行列、分组、方向和间距表达数量与类别关系，避免装饰性排列造成错误比较。
7. **配置图例与注释**：清楚说明符号含义、数量单位、统计口径和数据来源。
8. **进行理解测试**：检查读者是否能识别对象、读懂数量、比较类别，并发现可能的歧义。
9. **记录版本与证据**：保留符号规范、数据映射、测试结果和修订理由。

## 5. 视觉编码分析维度

| 维度 | 需要分析的问题 |
|---|---|
| 符号对象 | 一个图形代表什么人、物、事件或统计单位？ |
| 符号标准化 | 各符号是否遵循一致的造型、视角和比例规则？ |
| 数量单位 | 一个完整符号代表多少对象？是否存在分数符号？ |
| 重复与排列 | 符号如何通过阵列、行列或分组形成数量关系？ |
| 分类与色彩 | 颜色、形状是否区分不同群体或类别？ |
| 图例与说明 | 读者能否准确解读符号及其数量含义？ |
| 数据依据 | 统计口径、时间范围、来源和单位是否清楚？ |

## 6. 标签判定规则

建议统一使用标签：`ISOTYPE-基础图形设计`。

- **确认使用**：案例中存在系统化的象形符号语法，并且符号与统计对象、数量或分类关系之间有明确映射。
- **疑似使用 / 待核实**：画面存在重复象形图案或图像统计特征，但数量单位、符号规则或设计来源尚不清楚。
- **不适用**：图像主要用于装饰、场景说明或单个对象识别，没有形成图像统计符号系统。

每个案例应记录标签状态、支持判断的图像证据、符号代表的对象及数量单位、重复/分组/比例/图例规则，以及尚待核实的来源或数据口径。

## 7. 与信息图形分类的关系

一个案例应分别判断：

- **数据逻辑**：如编年、层级、编目、字母表、地理；
- **表现类型**：如混合型、列表型、流程图型、时间轴型、词云型；
- **基础图形设计标签**：如 ISOTYPE。

例如，一个地理信息图形可以采用地图作为主要表现形式，同时使用 ISOTYPE 式象形符号表达不同地区的人口数量。此时“地理型”是数据/表现组织分类，“ISOTYPE-基础图形设计”是基础设计方法标签，两者并不冲突。

- [CASE-0001｜兵马俑制作工艺信息图](../02-信息图形类型案例/05-流程图型-Process/案例/CASE-0001-兵马俑制作工艺信息图/README.md)：**不适用 / 证据不足**。现有案例分析记录显示该图使用手绘人物、工具和工艺示意符号，但没有证据证明其采用标准化、可重复且与统计数量对应的 ISOTYPE 图像统计系统。因此不应仅凭插画和图标将其标记为 ISOTYPE。该案例仅作为分类边界参照，不在本模块重复存储。

## 9. 研究与修订原则

- ISOTYPE 标签可以跨多个表现类型使用，不新增到信息图形类型序列。
- 只有在符号系统和数据映射有证据时才确认使用。
- 不能把所有 pictogram、icon array 或插画都自动归入 ISOTYPE。
- 新案例可补充或修正本文件的判断标准；理论修订应保留案例依据和待核实项。
