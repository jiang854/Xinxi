# 02｜图符语言与视觉编码

本目录研究 ISOTYPE 的图符语言、视觉编码与数量表达。原有「03-数量表达与符号规则」主题在本目录统一维护，不再作为独立目录。

## 一、图符语言

- **符号对象**：图符代表的人、物、群体、事件或统计单位。
- **语义稳定**：同一图符在同一系统内应保持一致含义；一符多义时必须明确区分。
- **造型规范**：记录视角、比例、轮廓、细节密度、线宽和色彩规则。
- **符号变体**：说明不同性别、年龄、类别、状态或场景是否使用变体，以及变体是否改变语义。
- **组合语法**：说明图符能否组合、叠加、分组或与文字/数字共同使用。

## 二、视觉编码

| 编码维度 | 需要明确的规则 |
|---|---|
| 图形形状 | 代表对象或类别，不能只靠装饰差异 |
| 大小 | 是否固定；若变化，变化是否有明确数据含义 |
| 颜色 | 类别区分、强调或数值分组；保持图例一致 |
| 方向 / 姿态 | 是否承载方向、状态或动作含义 |
| 排列 / 分组 | 行列、阵列、分区和阅读顺序 |
| 文字与图例 | 图符名称、单位、数量映射和必要注释 |

## 三、数量表达与符号规则

### 1. 数量单位

每个图像单位必须有明确代表值，例如“一个图符代表若干对象”。同一比较组中单位应一致；若因数据精度或展示需要使用不同单位，必须清楚标注，不能让读者误以为符号可直接比较。

### 2. 重复阵列

通过图符重复表达数量时，应保持图形尺寸一致、间距规则稳定，并采用可辨识的行列或分组结构。排列不应让装饰节奏掩盖数量差异。

### 3. 部分符号与舍入

若使用半个或部分图符，需解释其代表的比例。若不使用部分符号，应记录舍入、截断或区间化规则，并说明可能产生的误差。

### 4. 比例与面积

不能未经说明地同时用图符数量和图符大小表达同一数值。若大小本身也编码数据，应说明面积、长度或其他视觉量与数据之间的映射关系，避免面积误读。

### 5. 图例与数据口径

图例至少说明图符含义、一个图符代表的数量、统计总体、时间范围、单位和来源。读者应能从图面还原数量表达规则。

## 四、验证清单

- 图符能否被目标读者识别？
- 图符是否与统计对象一一对应？
- 同一图符是否始终保持同一语义？
- 数量单位和分数符号是否容易理解？
- 阵列和间距是否造成错误的视觉比较？
- 图例、单位、时间范围和来源是否齐全？
- 黑白打印、小尺寸或色觉差异条件下是否仍可读？

## 五、输出材料

建议将图符规范表、符号草图、编码对照表、数量换算表、图例规范和验证记录放在对应研究或设计实践文件中，并在本目录 README 中登记入口。
