# 03｜案例研究

本目录用于建立 ISOTYPE 专题案例档案，分析作品是否真正形成系统化的图像统计表达。当前没有足够材料将已有案例确认标注为 ISOTYPE，因此不预设虚构案例。

## 每个案例应记录

1. 案例编号、作品名称、作者/机构、年代和发布渠道。
2. 原始来源、图像版本、版权/授权状态。
3. 图符代表的对象、语义和造型规范。
4. 符号是否标准化、重复使用以及是否存在稳定的视觉语法。
5. 一个图符代表的数量、分数符号、排列和图例规则。
6. 数据来源、统计总体、时间范围、单位和口径。
7. ISOTYPE 判断：确认使用、疑似使用/待核实、不适用。
8. 支持判断的直接证据、分析推断和未解决问题。

## 案例比较

当积累足够案例后，可按符号对象、标准化程度、数量单位、阵列方式、图例、数据来源和传播目标进行横向比较。没有直接证据的字段应标注待核实，不作推断补全。
