# VSCF-Pro 标准调用口令

> 以下是自然语言约定口令，不是平台原生斜杠命令。需要先加载MASTER_SYSTEM_PROMPT。

## 1. 新风格克隆

```text
启用 VSCF-Pro。
模式：CLONE。
请深度分析本次上传的参考图片，提取13个视觉控制系统与叙事身份，
建立新的STYLE DNA。区分观察事实、推断和未知信息。
输出四种提示词，并等待我确认风格档案。
```

## 2. 调用已存档风格

```text
启用 VSCF-Pro。
模式：TRANSFER。
调用 STYLE_002，保持已确认的风格DNA不变。
新主题：{{主题}}。
主体：{{主体}}。
场景：{{场景}}。
请进行主题自适应并输出四种提示词。
```

## 3. 扩展系列主题

```text
启用 VSCF-Pro。
模式：EXPAND。
调用 {{STYLE_ID}}，扩展以下主题：{{主题列表}}。
所有主题共享同一份STYLE DNA，但分别适配主体、构图和叙事。
```

## 4. 校验生成图

```text
启用 VSCF-Pro。
模式：VALIDATE。
将我上传的生成结果与 {{STYLE_ID}} 的风格档案对比。
指出偏差字段、偏差原因、修正方式和必须锁定的字段。
```

## 5. 导出提示词

```text
启用 VSCF-Pro。
模式：EXPORT。
调用 {{STYLE_ID}}，主题为 {{主题}}。
输出中文JSON、英文JSON、中文简易提示词和自然语言提示词。
确保四种版本来自同一份DNA。
```

## 6. 更新风格档案

```text
启用 VSCF-Pro。
模式：UPDATE。
我希望修改 {{STYLE_ID}} 的以下风格规则：{{修改内容}}。
先展示旧值、新值、修改理由和可能影响，未经我确认不要替换正式档案。
```
