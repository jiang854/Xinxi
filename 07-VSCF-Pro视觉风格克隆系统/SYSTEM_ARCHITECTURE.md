# VSCF-Pro 系统架构与数据规范

## 1. 六层架构

| 层级 | 名称 | 输入 | 输出 |
|---|---|---|---|
| L1 | 输入层 | 参考图、主题、应用要求 | 标准化任务输入 |
| L2 | 分析层 | 参考图像特征 | 观察、推断、待确认记录 |
| L3 | DNA层 | 13项视觉分析与叙事分析 | STYLE DNA |
| L4 | 变量控制层 | 风格DNA、主题、应用 | 三层变量映射 |
| L5 | 提示词层 | 已确认档案与任务 | 四种提示词 |
| L6 | 校验层 | 生成图、档案、目标 | 偏差诊断与迭代记录 |

## 2. 13个视觉控制维度

1. 风格本体：艺术类别、媒介、风格边界。
2. 色彩：色相、明度、饱和度、冷暖、比例和关系。
3. 光线：方向、光质、光比、反射、阴影和空气感。
4. 构图：重心、层级、空间、留白、视线路径。
5. 尺度：主体/环境比例、透视和尺度张力。
6. 表现语言：摄影、绘画、矢量、3D、拼贴及混合。
7. 边缘：清晰、柔化、虚实和层级。
8. 完成度：主体、次要区域、背景的细节分配。
9. 信息密度：信息集中区与简化区。
10. 材质：表面、反射、粗糙度、纹理和触感。
11. 主体设计：轮廓、比例、动作和环境关系。
12. 视觉锚点：主要、次要、三级锚点及跨图锚点。
13. 张力：尺度、色彩、明暗、动静、疏密、虚实。

## 3. 三层变量

- STYLE INVARIANTS：决定风格身份，用户确认后锁定。
- THEME VARIABLES：决定本次画什么，可替换。
- APPLICATION VARIABLES：决定作品用途和输出约束，可按任务调整。

## 4. 证据分级

每个重要字段可附：
- `observed`：参考图直接可见；
- `inferred`：由可见特征推断；
- `unknown`：当前无法确认；
- `user_confirmed`：用户已确认。

置信度可用 high / medium / low，需说明依据。避免虚构精确色彩比例、光照角度或尺寸。

## 5. 档案状态

`provisional` → `reviewed` → `tested` → `stable`

状态升级条件：
- provisional：完成初步提取。
- reviewed：用户审核关键字段。
- tested：完成真实图像生成和跨主题比较。
- stable：多参考样本、多主题验证均保持核心风格锚点。

## 6. 四种输出一致性

中文JSON、英文JSON、中文简易提示词、自然语言提示词必须共用同一档案ID、版本号和主题输入。简易版可以压缩表达，但不能删除核心锚点；自然语言版可以展开表达，但不能添加档案中不存在的风格结论。

## 7. 评分建议

可按100分做辅助诊断：
- 风格身份与锚点：25；
- 色彩、光线和构图：25；
- 表现语言与材质：20；
- 主题适配：20；
- 应用与文字约束：10。

评分需附证据；关键锚点漂移不能被其他维度高分抵消。
