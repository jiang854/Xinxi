# START HERE｜VSCF-Pro 启动入口

## 1. 最快的使用方式

将本模块的 `MASTER_SYSTEM_PROMPT.md` 加载到当前AI会话、项目指令、智能体指令或知识库中。首次加载时同时提供 `SYSTEM_ARCHITECTURE.md` 和 `JSON_SCHEMA.json` 作为规则与数据结构参考。

然后上传要克隆的参考图片，发送：

```text
启用 VSCF-Pro，执行【风格提取模式】。
请深度分析我刚上传的参考图，提取独立 STYLE DNA，
区分风格恒定项、主题变量和应用变量，
并输出中文JSON、英文JSON、中文简易提示词、自然语言提示词。
未经我确认，不要把推断信息写成已确认事实。
```

## 2. 五种标准调用模式

### A. 新风格提取

```text
VSCF:CLONE
请对本次上传图片执行完整风格克隆，建立新的STYLE档案。
```

### B. 调用已有风格迁移主题

```text
VSCF:TRANSFER
调用 STYLE_002。保持原始风格DNA不变，
将主题替换为：{{新主题}}。
```

### C. 同风格主题扩展

```text
VSCF:EXPAND
调用 STYLE_002，扩展以下主题系列：{{主题列表}}。
所有输出共用同一份风格DNA。
```

### D. 风格一致性校验

```text
VSCF:VALIDATE
请将新生成图片与 STYLE_002 的风格DNA逐项比较，
指出风格漂移字段和修正建议。
```

### E. 导出四种提示词

```text
VSCF:EXPORT
调用 STYLE_002，输出中文JSON、英文JSON、
中文简易提示词和自然语言提示词。
```

> `VSCF:CLONE` 等是写给AI识别的标准自然语言触发口令，不是GitHub命令，也不是所有平台都原生支持的斜杠命令。只有在加载了VSCF-Pro系统规则后，它们才具有约定的执行含义。

## 3. 建议的实际工作流程

1. 上传参考图。
2. 使用 `VSCF:CLONE`。
3. 审核AI生成的STYLE DNA，纠正错误或确认推断。
4. 将确认后的档案保存为 `profiles/STYLE_xxx/`。
5. 上传新主题或描述新主题。
6. 使用 `VSCF:TRANSFER` 或 `VSCF:EXPAND`。
7. 生成图像后使用 `VSCF:VALIDATE`。
8. 只有确认风格档案发生变化时，才升级该STYLE版本。

## 4. 重要约束

- 新参考图不自动覆盖旧STYLE档案。
- 新主题不自动改变STYLE DNA。
- 未经用户确认，不将单图推断升级为已验证规则。
- 未经用户明确要求，不复用参考图的品牌名称、原文案、人物身份或受版权保护的具体内容。
- 每次调用都应说明本次实际读取了哪些风格档案；如果AI无法访问仓库，应要求用户上传相应文件，不得假装已读取。
