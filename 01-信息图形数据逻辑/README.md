# 01｜信息图形数据逻辑

本模块研究信息图形如何组织对象、事件、属性和空间关系。当前知识体系包含五类基础数据架构逻辑：

1. [编年型信息图形](01-编年型信息图形概念定义.md)
2. [层级型信息图形](02-层级型信息图形概念定义.md)
3. [编目型信息图形](03-编目型信息图形概念定义.md)
4. [字母表型信息图形](04-字母表型信息图形概念定义.md)
5. [地理图形信息图形](05-地理图形信息图形概念定义.md)

分析时应分别记录主逻辑、辅助逻辑和更精确的对象关系。数据逻辑不等同于整张作品的视觉表现类型；案例图片和逐案分析统一归档于 [02 信息图形类型案例](../02-信息图形类型案例/README.md)。

各定义文档建议持续记录：概念定义、数据对象、关系结构、适用条件、视觉表达、典型案例、边界与参考来源。
