# 01 编年型信息图形概念定义

> 状态：初始理论框架，待用户案例图验证与修订。  
> 案例连接：[时间轴型信息图形](../02-信息图形类型案例/03-时间轴型-Timeline/00-标签说明.md)。

## 概念定义

编年型信息图形以事件发生的先后顺序作为核心组织逻辑，将事件、阶段、变化或发展过程按照时间关系编排，使读者理解何时发生、先后如何、持续多久、前后如何关联。其本质不是画面中出现日期，而是信息对象之间存在可识别的时间关系。时间可以是连续尺度，也可以是离散阶段；时间间隔可以等距或不等距，取决于叙事目标和数据真实性。

编年型强调数据组织原则；时间轴型强调以时间轴为主要视觉结构。案例可以采用列表、地图、分栏或路径表达编年逻辑，不一定使用传统时间轴。

## A. 基本的数据逻辑

典型事件记录包含：事件编号、事件名称、开始时间、结束时间、时间精度、类别/主题、主体、地点、说明、事件关系和来源。

核心关系：
- 顺序关系：事件 A 早于、晚于或同时于事件 B。
- 时长关系：事件持续多久、阶段覆盖多长时间。
- 间隔关系：相邻事件之间相隔多久。
- 并行关系：不同主体在同一时间段发生的事件。
- 因果/影响关系：必须有独立证据，不能仅凭时间先后推断因果。

判断要点：
1. 时间是连续值还是阶段标签。
2. 日期精度是年、月、日还是更细。
3. 区分事件发生时间、持续区间、统计周期和叙述时间。
4. 若间隔具有比较意义，应保留真实比例；若为阅读而调整，应标注非比例示意。
5. 多条事件线需保留主体或主题字段。

## B. 统计图形与计算方式

常见图形：时间轴/刻度轴、时间序列折线图、区间条/甘特式条带、里程碑点图、分组柱状图、面积图和多泳道时间轴。

常见计算：
- 持续时间 = 结束时间 - 开始时间。
- 事件间隔 = 下一事件开始时间 - 当前事件结束时间。
- 变化量 = 本期数值 - 上期数值。
- 变化率 = 变化量 / 上期数值；基期为零时需另行处理。
- 时间密度 = 单位时间内事件数量，需说明统计窗口和计数规则。

若只是编排历史事件，不必强行添加统计计算。若使用数量、比例或趋势图，应核对单位、基数、时间窗口和计算口径。

## C. 视觉编码

- **点**：单点表示事件或里程碑；大小仅在映射规模、影响程度或数量时变化；形状可区分类别。
- **线**：主轴表达时间方向；连接线表达明确关联；平行线/泳道表达多个主体；虚线可表示不确定或间断，需图例说明。
- **面与体**：条带或色块表示区间、阶段；面积只有在有量化含义时才用于比较；立体效果不得造成时间长度或数量误读。
- **符号与文字**：图标区分事件类别；日期、标题、说明建立字号层级；重要事件可通过标签、描边或局部放大突出。
- **色彩与尺度**：同类事件保持一致颜色；等距排布代表等时间间隔；非等距需忠实反映间隔或标注示意。

## D. 数据/信息架构

常见结构：
1. 单线顺序结构。
2. 分阶段结构。
3. 多主体并行结构。
4. 主题分组结构。
5. 事件—影响关系结构。

信息层级通常为主题标题 → 时间范围/阶段 → 关键事件 → 事件解释 → 来源与注释。事件过多时可阶段折叠、筛选重点或局部放大；筛选规则应透明。

## E. 视觉叙事架构

典型路径：明确时间范围与主题 → 按时间推进 → 突出关键转折 → 展示必要的并行事件 → 呈现阶段结果或当前状态。标题、阶段命名、节点关系和解释文字应帮助读者理解变化意义，而不只是看到日期排列。

## 适用边界与常见误区

适合历史演进、项目进程、人物经历、技术发展和政策沿革。若主要问题是包含关系，优先考虑层级型；若主要问题是有哪些项目，优先考虑编目型。不要把时间顺序自动解释为因果，也不要混用不同时间精度而不作说明。

## 课程理论校订｜《第三讲—信息图形类型学》（2026-11-19）
**依据**：课件第2—5页，尤其第3页提出“数据逻辑：单向、不可逆、顺序排列；数据维度：单维为主，较少延伸数据；视觉编码：线性为主，具高度可变性”。此表述是课程中的**典型特征**，不是排除多维度、环形或多路径作品的绝对判据。

### A 数据本质：顺序如何成立
数据对象可以是日期事件，也可以是按阶段演进的活动。形式化记录为 `(id, order/time, stage, predecessor, duration?, attributes?)`。以明确时间先后为主的属于严格编年；只具有操作依赖顺序的生产过程，应进一步标记“流程逻辑”，不能因为有箭头就直接判成按时间比例组织的时间轴。

### B 统计与计算
课程第3—5页以时间线、径向布局与多事件线示范“线性编码的高度可变性”。如有度量，可计算时间间隔、持续时间、阶段频次、增减量；纯步骤叙事不必强行采用数值图表。**顺序序号不等于日期，顺序间距不等于时间长度。**

### C 视觉编码
点＝事件节点；线＝时间轴、连续路径或关系线；面＝阶段与持续区间；体＝场景化辅助、不能替代量化刻度；符号＝人物/动作/类别；色彩＝阶段连续或重要转折。曲线、环线、折线可改变画面形态，但必须保留方向标记与顺序可读性。

### D 信息架构
从研究问题建立“总体主题—阶段—事件/工序—证据或说明”的信息树；为并行事件设置支线。核查阶段是否依赖时间、因果还是工艺前置条件；三者应分别标注。

### E 视觉叙事
典型阅读链为背景→起点→阶段推进→关键变化→结果。工艺图可采用“原料→加工→成品”的过程叙事，但要注明其核心是**程序性依赖**而非历史编年。与课件第25页“示意图型”和第26页“流程图型”是**交叉分类**而非同一层级。
