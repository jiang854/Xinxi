# 04 视觉编码与图表选型

## 1. 先问分析问题，再选图形

选图不应从“哪个图形更漂亮”开始，而应从读者需要完成的比较任务开始。

| 分析任务 | 首选候选 | 需要检查的条件 |
|---|---|---|
| 比较类别数量/数值 | 条形图 | 类别是否清楚；是否需要排序；是否有负值 |
| 比较多个系列 | 多组条形图 | 同一类别下是否需要并列比较；尺度是否一致 |
| 看总量与组成 | 堆叠条形图 | 各组成项是否可相加；比较重点是总量还是局部 |
| 看整体构成比例 | 饼图/环形图 | 是否为同一整体；分类数是否适中；总和是否有意义 |
| 看连续趋势 | 折线图 | X 是否连续或有序；缺失点如何处理 |
| 看多类别随时间的构成 | Streamgraph | 是否接受堆叠基线变化；是否需要绝对值 |
| 看排名变化 | Bump chart | 排名定义是否明确；是否只强调次序 |
| 看持续区间和重叠 | Gantt chart | 开始/结束值是否可靠；区间是否可能重叠 |
| 看中位数和离散程度 | 箱线图 | 是否需要显示分布细节与离群点 |
| 看分布形态 | 小提琴图 | 分箱数和样本量是否足够；是否需显示原始点 |
| 保留每个观测点 | Beeswarm | 点数是否过多；避让位移是否会被误读 |
| 看两个连续变量关系 | 散点/气泡图 | 点重叠、尺度、异常值和相关不等于因果 |
| 看二维聚集密度 | 六边形分箱/等高线 | 前者为格网计数，后者为密度估计 |
| 看多个连续指标 | 平行坐标/雷达图 | 指标尺度、轴顺序、线条重叠 |
| 看对象之间的流向 | Sankey | 方向和流量是否有意义；边宽是否有明确单位 |
| 看多阶段类别迁移 | Alluvial | 各阶段类别如何对应；流量是否为记录数或数值权重 |
| 看层级构成 | Treemap/Sunburst | 层级是否真实；面积/角度是否代表权重 |
| 看网络关系 | Arc/Chord | 关系有向性、边权重、节点排序和交叉复杂度 |
| 看空间分区 | Voronoi diagram | 最近邻区域是否真是研究问题；点位置是否有空间意义 |

## 2. 视觉通道与数据类型

视觉编码是把数据变量映射到图形属性。常见视觉通道如下：

| 视觉通道 | 常见图形属性 | 常见数据用途 | 风险 |
|---|---|---|---|
| 位置 | X/Y坐标、轴位置 | 连续值、类别顺序、时间 | 不同面板尺度不一致会影响比较 |
| 长度 | 条形长度、线段长度 | 数量、差值 | 起点不为零可能夸大差异 |
| 角度 | 饼图扇区角度、弦图弧度 | 整体构成、关系量 | 人眼不易精确比较相近角度 |
| 面积 | 气泡、Treemap矩形、圆面积 | 数量、权重 | 面积与半径/边长不可混淆 |
| 颜色明度/色相 | 连续色带、分类色 | 强度、类别、正负 | 色带顺序、色盲可读性和图例必须检查 |
| 形状 | 点形、符号 | 分类 | 可区分类别数量有限 |
| 方向 | 箭头、流向 | 有向关系、过程 | 没有箭头或语义说明时方向可能不明确 |
| 连通性 | 线、弧、流带 | 关系、路径、迁移 | 交叉过多会降低可读性 |
| 纹理/分区 | 网格、条纹、嵌套 | 分组、层级 | 装饰纹理不能伪装成数据编码 |

## 3. 面积与半径：必须分清

当数值通过圆形大小表达时，如果目标是让**面积**与数值成比例，半径应与数值平方根成比例。RAWGraphs 的气泡、圆形打包等实现中可以看到 `scaleSqrt`，而非直接用线性半径表达数值。

若半径直接与数值成比例，面积会按数值平方增长，造成夸大。类似地，Treemap 面积、饼图角度、Sankey 连线宽度也必须确认它们对应的权重口径。

## 4. 比例、基线与归一化

- 条形图：比较长度通常应从共同基线开始，尤其是零值具有意义时。
- 堆叠图：各分段可比较组成，但中间段不共享同一基线，精确比较困难。
- 100%堆叠/Expand：突出相对构成，隐藏绝对总量差异。
- Streamgraph 的 Silhouette/Wiggle：改变整体基线以改善形态，不应把基线位置解释为零值。
- Bump chart：位置表示排序或名次，需说明第一名在上还是下，不能当成原始值曲线。

## 5. 颜色映射

- 分类变量：使用可区分、稳定的分类色；同一类别在整份作品中保持一致。
- 连续变量：使用有序色带，颜色变化方向与数值顺序一致。
- 发散变量：以有意义的中心值为中点，正负两侧使用不同色相或明度。
- 关系网络：节点/边颜色可表示类别或来源，但需要明确颜色映射对象。
- 颜色图例必须说明变量、单位、方向和类别；不能仅靠颜色深浅让读者猜测含义。

## 6. 多面板与多系列

RAWGraphs 多种图表支持把多个系列分面排列，并提供是否共用尺度的选项。这里存在重要取舍：

- **共用尺度**：适合跨面板比较绝对值，但小量级系列可能难以辨认。
- **各自尺度**：利于观察每个系列内部形态，但面板间高度不可直接比较。
- **排序**：按总值排序能突出规模差异，但会改变类别阅读顺序；原始顺序则保留数据输入秩序。
- **标签**：标签密度、避让和自动隐藏会影响可读性；重要数据不应只依赖悬停提示。

## 7. 选型检查清单

- [ ] 读者要比较的是类别、时间、分布、构成、关系、层级还是空间？
- [ ] 一行数据代表什么？统计单位是否一致？
- [ ] 聚合方式是 count、sum、mean、min、max，还是保留原始记录？
- [ ] 是否有正确的分母、基线、单位和时间范围？
- [ ] 位置、长度、角度、面积、颜色、线宽各自代表什么？
- [ ] 是否把布局避让、堆叠偏移或几何分区误读为统计值？
- [ ] 多面板是否共用尺度？类别是否排序？
- [ ] 图例是否写清变量、单位、颜色方向和必要的计算口径？
- [ ] 是否有缺失值、零值、负值、重复记录或小样本问题？
- [ ] 该图是否真的比表格或直接标注更容易回答研究问题？

## 8. 选型的底线

不要把“图形复杂”当成“分析更深入”。当图形需要大量解释才能说明某个视觉属性代表什么时，应重新评估是否有更直接的编码方式。统计图形的首要任务是忠实呈现数据关系，其次才是视觉风格和叙事吸引力。
