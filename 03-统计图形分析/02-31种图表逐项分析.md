# 02 31种图表逐项分析

> 本文以 RAWGraphs Charts master 分支 src/index.js 导出的 31 个图表模块为对象。描述的是该仓库的实现和设计意图；适用场景与风险是基于源码的分析建议，不代表统计学中唯一标准定义。

## 一、类别比较与构成

### 1. Bar chart｜条形图
- **输入**：必需类别 bars；可选数值 size、颜色 color、系列 series。
- **计算**：按系列和类别分组；size 映射数值时聚合，未映射时以组内记录数 v.length 作为大小。
- **编码**：类别映射离散位置，size 映射条长；支持横/纵向、排序、颜色和多系列面板。
- **适用**：比较离散类别数量或汇总值。
- **边界**：核对共同基线、聚合口径和面板尺度；记录数不等于数值总和。

### 2. Multi-set bar chart｜多组条形图
- **输入**：必需分组 groups 和多个数值字段 bars；可选 series。
- **计算**：对每个分组/系列分别聚合多个数值字段，每个字段生成一根条。
- **编码**：组别形成主位置，各数值字段在组内并列。
- **适用**：同一类别下并列比较多个指标。
- **边界**：指标单位不同时不能共用同一数值轴；指标间大小比较可能无意义。

### 3. Stacked bar chart｜堆叠条形图
- **输入**：必需横轴分组 stacks 和多个数值字段 bars；可选 series。
- **计算**：各数值字段聚合后通过 D3 stack 堆叠。
- **编码**：总条长及组成段；颜色区分组成字段。
- **适用**：比较类别总量及其组成。
- **边界**：只有第一段共享零基线，中间段不适合精确比较；百分比堆叠会隐藏绝对总量。

### 4. Pie chart｜饼图/环形图
- **输入**：多个数值字段 arcs，可选 series。
- **计算**：按系列聚合各字段，计算总量，再将各项数值转换为角度。
- **编码**：扇区角度表示部分占整体比例；可采用环形、多个饼图网格和数值标签。
- **适用**：少量组成部分构成一个有意义整体。
- **边界**：组成项必须同口径、可相加且总和有意义；相近扇区难以精确比较。圆半径还可按总量平方根缩放。

### 5. Matrix plot｜矩阵图
- **输入**：必需 X、Y 两个分类/离散维度；可选 size、color、label。
- **计算**：按 X/Y 组合分组；size 可来自数值聚合或记录数。
- **编码**：行列构成矩阵，单元格符号大小和颜色编码数值。
- **适用**：比较两个类别维度交叉后的关系或频次。
- **边界**：空白格要区分零与无数据；颜色和大小同时编码时须有清楚图例。

## 二、时间变化与区间

### 6. Line chart｜折线图
- **输入**：X、Y 必需；可选 lines、series、color。
- **计算**：按系列/线组和 X 分组；Y 可聚合；再按 X 排序。
- **编码**：X/Y 位置表示时间或连续变量，线连接观测点。
- **适用**：连续变量或时间序列趋势。
- **边界**：连接线暗示点间连续；不规则时间间隔不能被等距类别轴掩盖；插值不会增加真实观测。

### 7. Horizon graph｜地平线图
- **输入**：连续 X、数值 Y，可选分组。
- **计算**：按组和 X 聚合 Y；正负值拆成若干 bands。
- **编码**：正负区域分带叠加或镜像，颜色区分正负，以压缩纵向空间。
- **适用**：有限高度中比较多条时间序列波动。
- **边界**：压缩色带不等于原始面积；需说明带数、负值处理和颜色语义。

### 8. Streamgraph｜河流图/流图
- **输入**：X、类别 streams、数值 size，可选 series。
- **计算**：按系列、X、stream 分组聚合；使用 D3 stack，可选排序和 offset。
- **编码**：流带厚度对应数值，曲线面积呈现多类别变化。
- **适用**：比较多个类别随时间/连续维度变化的构成。
- **边界**：Wiggle、Silhouette 等 offset 会移动基线；垂直位置不再等于绝对值。源码拒绝负数 size；Expand 表达相对比例而非绝对总量。

### 9. Bump chart｜排名变化图
- **输入**：连续 X、类别 streams；可选 size 和 rank。
- **计算**：按系列、类别和 X 聚合；通过堆叠/重排逻辑调整各类别的垂直顺序，可由 rank 决定顺序。
- **编码**：曲线在不同 X 位置的上下排序表示名次变化。
- **适用**：名次、排序或相对位置变化。
- **边界**：源码拒绝负值；必须明确第一名方向、排名来源及并列处理。曲线高度不代表原始数量。

### 10. Gantt chart｜甘特图
- **输入**：开始值、结束值必需；可选分组和颜色；开始/结束字段须同为日期或数值。
- **计算**：按组组织任务，按开始时间排序，通过区间重叠检测分配垂直轨道。
- **编码**：X 轴表示日期/数值区间；条形起点和长度表示开始与持续时间；Y 轨道用于避让。
- **适用**：项目任务、任期、活动周期和区间重叠。
- **边界**：垂直轨道通常只是布局结果，不是任务等级；需确认端点相接与零时长的处理规则。

## 三、分布、相关与多变量

### 11. Beeswarm plot｜蜂群图
- **输入**：连续 X 必需；可选分组、点大小、颜色、标签。
- **计算**：保留观测记录，按组排序；用力模拟和碰撞半径减少点重叠。
- **编码**：X 表示数值；Y 主要用于分组和避让；点大小可编码额外数值。
- **适用**：显示单个观测值分布并保留样本点。
- **边界**：避让后的 Y 位移不是第二个测量变量；样本过大仍会拥挤。

### 12. Box plot｜箱线图
- **输入**：数值必需；可选分组和颜色。
- **计算**：按组排序数值，计算最小值、Q1、中位数、Q3、最大值；IQR=Q3−Q1；须端点按 IQR 倍数与实际极值截取，须外记录为离群点。
- **编码**：箱体表示 Q1–Q3，中线表示中位数，须表示设定范围，离群点以点呈现。
- **适用**：比较多组分布中心和离散程度。
- **边界**：仓库实现的须端点为 max(min, Q1−k·IQR) 与 min(max, Q3+k·IQR)；离群规则受 iqrMultiplier 控制。

### 13. Violin plot｜小提琴图
- **输入**：数值必需；可选分组和颜色。
- **计算**：按组分组，将数值用 D3 bin 分箱；每箱观测数量决定轮廓宽度。
- **编码**：纵向位置表示数值，横向宽度表示该区间记录量；可叠加原始点。
- **适用**：比较多组分布形态。
- **边界**：该实现是分箱计数构造对称轮廓，不应无条件称为核密度估计；分箱数会改变形状。

### 14. Bubble chart｜气泡图
- **输入**：X、Y 必需；可选 size、color、label、connectedBy、series。
- **计算**：映射层保留记录；渲染层按系列分面，建立 X/Y 和 size 尺度；可按连接字段排序连线。
- **编码**：X/Y 表示两个连续变量；圆面积通过平方根尺度与 size 对应；颜色表示类别或数值。
- **适用**：观察两个变量关系，并展示额外变量。
- **边界**：面积而非半径应对应数值；不同面板可共用或独立尺度；相关不等于因果。

### 15. Contour plot｜等高线密度图
- **输入**：X、Y 两个连续维度。
- **计算**：调用 d3-contour 的 contourDensity 对二维点云密度估计；bandwidth 控制平滑程度。
- **编码**：等密度轮廓围出聚集区域，颜色编码密度层级；可叠加原始点。
- **适用**：散点重叠严重时观察二维密度结构。
- **边界**：带宽改变峰值、边界和聚集形态；它不是地理海拔线，也不是原始点间真实边界。

### 16. Hexagonal binning｜六边形分箱图
- **输入**：X、Y 两个连续维度。
- **计算**：使用 d3-hexbin 将点分配到六边形网格；每个 bin 的长度即该格观测数。
- **编码**：六边形位置表示 X/Y 区域，颜色表示计数；可让面积随计数变化并叠加原始点。
- **适用**：二维散点多、重叠严重，需要观察局部计数密度。
- **边界**：网格直径影响聚集细节；格内数量不是连续密度估计。

### 17. Convex hull｜凸包图
- **输入**：X、Y 必需；可选分组和标签。
- **计算**：按组收集坐标，使用 d3.polygonHull 计算包含点集的最小凸多边形。
- **编码**：包络面和描边区分组别；可显示点。
- **适用**：比较不同类别点集的外部空间范围。
- **边界**：凸包会填满凹陷区域，不表示真实边界、密度或点间连通；离群点可能扩大包络。

### 18. Voronoi Diagram｜Voronoi 图/泰森多边形
- **输入**：X、Y 点位；可选颜色和标签。
- **计算**：将点映射到绘图区，建立 Delaunay 三角剖分并生成 Voronoi 单元。
- **编码**：每个单元包含离其生成点最近的空间区域；填色可编码类别或指标。
- **适用**：最近邻服务区、点位影响区域或空间分区。
- **边界**：单元面积由点位置和边界决定，不等于该点数量或权重；需说明范围与距离度量。

### 19. Parallel coordinates｜平行坐标图
- **输入**：多个连续字段；可选颜色。
- **计算**：每条记录保留为多维数值序列；每个维度分别建立自己的线性尺度。
- **编码**：多个平行轴表示指标，一条折线穿过各轴的对应值；颜色可表示类别。
- **适用**：观察多变量记录模式、组合和异常。
- **边界**：各轴通常各自缩放，轴间距离不可直接比较原始单位；轴顺序影响交叉形态，大量记录会过度叠线。

## 四、网络与流向

### 20. Arc Diagram｜弧线关系图
- **输入**：Source、Target 必需；可选关系权重 size。
- **计算**：按 Source–Target 汇总关系，建立节点和边，计算节点总值、入/出关系与连接度；可用 Louvain 社群算法辅助排序。
- **编码**：节点沿水平基线排列，弧线连接节点，线宽映射权重；节点大小可按总值、度数或入/出度设置。
- **适用**：展示节点关系与连接模式。
- **边界**：节点顺序显著改变交叉和弧线形态；社群排序是布局辅助，不是因果或类别真值。无权重时每条聚合边赋值 1，不是原始记录频次。

### 21. Chord Diagram｜弦图
- **输入**：Source、Target 必需；可选 size 权重。
- **计算**：将关系边转为节点邻接矩阵，再通过 D3 chordDirected 计算群组弧段和弦带。
- **编码**：圆周弧段代表节点，弦带连接源和目标，宽度表示关系权重。
- **适用**：观察有限节点间多方向关系和关系量。
- **边界**：矩阵构造和节点顺序影响结果；重复边的预聚合口径应核验；弦带过多会难读。

### 22. Sankey Diagram｜桑基图
- **输入**：Source、Target 必需；可选数值 size。
- **计算**：按 Source–Target 汇总，生成节点和有向边；d3-sankey-circular 计算节点位置、流量和连线宽度，支持循环链接。
- **编码**：矩形节点表示类别/阶段，节点高度与汇总值相关；连线宽度表示流量，方向表示源到目标。
- **适用**：能量、资金、物料、用户或状态流动。
- **边界**：需明确流量口径；未映射 size 时每条聚合关系边赋值 1，并非原始记录频次。循环流需标注。

### 23. Alluvial Diagram｜冲积图
- **输入**：至少两个有序阶段字段 steps；可选数值 size。
- **计算**：对每一对相邻阶段字段分组；流量为映射数值聚合值，或未映射时的组内记录数。
- **编码**：阶段节点按列排列，相邻阶段间以曲线流带连接，节点高度和流带宽度对应 value。
- **适用**：类别在多个阶段之间的迁移、分类变化和路径分布。
- **边界**：字段顺序即阶段顺序，不等于真实时间，除非阶段具有时间含义；需核验跨阶段记录是否可追踪。

## 五、层级结构与空间组成

### 24. Linear dendrogram｜线性树状图
- **输入**：多个层级字段；可选 size、color、label。
- **计算**：按层级字段依次嵌套分组，构造 D3 hierarchy；按叶节点权重汇总；使用 tree 或 cluster 布局。
- **编码**：根节点向叶节点横向展开，连线表示父子关系，节点大小可表示权重。
- **适用**：分类树、谱系、组织和概念分支。
- **边界**：树布局表达关系，不自动表达数值；多重父节点可能不适合单树结构。

### 25. Circular dendrogram｜圆形树状图
- **输入**：多级层级字段；可选 size、color、label。
- **计算**：构造 hierarchy 并汇总叶节点权重，使用 radial tree/cluster 计算节点角度与半径。
- **编码**：根节点在中心，分支向外放射；连线表达层级，可用节点大小和颜色增加属性。
- **适用**：分支较多且希望压缩横向空间的层级展示。
- **边界**：外圈标签易拥挤；径向角度和路径长度需谨慎比较。

### 26. Circle Packing｜圆形打包图
- **输入**：多个层级字段；可选 size、color、label。
- **计算**：构造嵌套 hierarchy；叶节点权重来自映射数值聚合或记录数；d3.pack 计算嵌套圆位置和半径。
- **编码**：嵌套圆表示包含层级，叶节点圆面积受权重影响。
- **适用**：多层级类别组成，强调嵌套与整体结构。
- **边界**：圆形打包会有空隙，面积比较不如矩形树图直观；需确认叶节点权重。

### 27. Treemap｜矩形树图
- **输入**：多个层级字段；可选 size、color、label。
- **计算**：分层汇总并构造 hierarchy；叶节点权重映射到 D3 treemap；支持 Squarify、Slice、Dice、Binary 等切分方法。
- **编码**：嵌套矩形表达层级，矩形面积映射权重，颜色表达类别或数值属性。
- **适用**：有限面积中显示大量类别及其占比。
- **边界**：矩形形状受切分算法影响，长宽比不是额外数据；小矩形难标注；跨层级比较须明确分母。

### 28. Sunburst diagram｜旭日图
- **输入**：多级层级字段；可选 size、color、label。
- **计算**：构造 hierarchy 并汇总叶节点权重，使用分区布局将层级转换为角度和径向层次。
- **编码**：中心是根节点，向外是子层级；扇区角度表示分支权重比例。
- **适用**：多层级类别组成和向下展开关系。
- **边界**：不同半径的扇区面积同时受角度与半径影响；比较权重应依据角度/层级定义，而非只凭整体面积。

### 29. Voronoi Treemap｜Voronoi 树图
- **输入**：多级层级字段；可选 size、color、label。
- **计算**：构造 hierarchy，再用 Voronoi treemap 迭代剖分；支持随机种子、裁剪多边形、边数和旋转。
- **编码**：不规则多边形单元表达层级和权重，颜色区分类别。
- **适用**：以不规则细胞形态表现层级组成。
- **边界**：仓库说明指出迭代计算可能导致面积不完全代表映射值；随机种子影响可复现性。

## 六、多指标轮廓与两端比较

### 30. Radar chart｜雷达图
- **输入**：至少 3 个数值指标 axes；可选颜色和系列。
- **计算**：每条记录展开为多个轴值；系列内组织数据，建立径向位置和数值尺度。
- **编码**：指标围绕中心径向排列，点连接成闭合轮廓；可显示点、填充和不同曲线插值。
- **适用**：少量对象在同一组多指标上的轮廓对照。
- **边界**：指标应同向或合理标准化；轴顺序改变面积和形状；面积不应直接当总体表现分数。

### 31. Slope chart｜斜率图
- **输入**：Source、Target 两个数值/日期端点；可选名称、颜色、系列。
- **计算**：每条记录保留两端值；使用共同 Y 尺度，将对象两端连接。
- **编码**：两列位置表示两个状态/时点；线段方向和斜率表达变化。
- **适用**：比较对象在两个时间点、条件或排序状态之间的变化。
- **边界**：只有两个端点，不能揭示中间过程；尺度和排序要统一；交叉过多需考虑排序和标签避让。

## 七、不计入 31 种图表的模块

- **Color test**：颜色比例尺调试模块，不是面向分析任务的统计图表。
- **Empty chart / Empty chart series**：创建新图表时使用的开发脚手架。
- **charts-utils.js**：共享坐标轴与刻度辅助函数。
- **styles / d3-styles.js**：样式模块。

## 八、逐图分析通用模板

后续新增图表或分析真实信息图案例时，统一记录：名称与来源；分析任务；输入记录单位和字段；分组、筛选、聚合与派生计算；布局算法和排序；视觉通道；尺度、分母、基线、单位和图例；适用条件；误读风险；在整张信息图中的角色（主图、辅助统计图、示意图或非统计图形）。
