# 03 统计图形分析

本目录研究统计图形的**数据要求、统计计算、视觉编码、布局算法与适用边界**。它以 RAWGraphs Charts 的公开源代码为技术样本，不把软件中的图表菜单直接当作完整的统计学分类，也不把单个图表等同于整张信息图形。

## 一、在知识库中的位置

本知识库将几个层次分开研究：

- **01 信息图形数据逻辑**：信息对象之间是什么关系——编年、层级、编目、字母表、地理。
- **02 信息图形类型案例**：整张作品主要采用什么视觉组织方式——混合型、文字/列表型、时间轴型、流程图型等。
- **03 统计图形分析**：其中某个图表如何处理数据、执行统计计算，并将结果映射为位置、长度、面积、角度、颜色、连线或空间分区。
- **ISOTYPE-基础图形设计**：横向的视觉表达方法，不是统计图形类型，也不是信息图形表现类型。

三者可以交叉：一张以时间顺序组织的混合型信息图，可以嵌入折线图；一个层级型信息图可以使用矩形树图；一张目录式信息图也可以嵌入条形图比较条目属性。

## 二、研究来源与范围

**主要来源：** [rawgraphs/rawgraphs-charts](https://github.com/rawgraphs/rawgraphs-charts)

本次以该仓库 `master` 分支为阅读对象。仓库 `package.json` 标记版本为 `v1.1.0`；本次读取的 Git tree SHA 为 `cade3b6e1b4d35d365440b1365d51b0dd48c9bce`。

仓库自述：它是 RAWGraphs 应用所采用图表的精选集合，通过 RAWGraphs Core API 定义图表行为，并提供本地 sandbox 环境。它不是统计学教材，也不是所有可能图表的百科全书。项目说明还明确表示，图表集合经过项目筛选，不以收录所有图表为目标。

源代码范围：
- `src/index.js` 导出 **32 个模块**：其中包括 31 个图表模块和 1 个 Color test 调试模块。
- `src/empty_chart` 与 `src/empty_chart_series` 是开发新图表的脚手架，不是正式导出的图表。
- `src/styles`、`src/charts-utils.js`、`src/d3-styles.js` 等提供共享样式和辅助函数。
- `example/configurations` 包含 39 个图表配置示例；`example/datasets` 包含 30 份示例数据文件。

## 四、RAWGraphs 图表模块的共同结构

多数图表目录采用相似的模块结构：

| 文件 | 作用 | 研究时要回答的问题 |
|---|---|---|
| `metadata.js` | 名称、说明、内部类别、教程链接 | 作者认为图表要表达什么 |
| `dimensions.js` | 输入维度、字段类型、必选/可选、多字段与聚合规则 | 数据表必须提供哪些字段 |
| `mapping.js` | 将原始记录变为图表需要的数据结构 | 原始数据怎样分组、汇总或转换 |
| `render.js` | 计算尺度、布局和绘制图形 | 统计结果如何成为视觉对象 |
| `visualOptions.js` | 可调参数 | 哪些布局、排序、比例、颜色和标签可以调整 |
| `*.svg` / `*_thumb.svg` | 图标和缩略图 | 软件界面如何识别图表 |

因此，分析一种统计图形不能只看缩略图。应同时读 `dimensions`、`mapping` 和 `render`：图形外观相似，不代表输入结构和计算逻辑相同。

## 五、阅读与引用原则

- **源代码事实**：以 RAWGraphs 仓库的字段定义、映射代码和绘制代码为准。
- **图表说明**：优先保留 `metadata.js` 的原始定位；当代码实现与文字说明不完全一致时，明确指出差异。
- **分析推断**：对适用场景、误读风险和选型的解释，标为研究分析，不冒充仓库原文。
- **数据口径**：每次案例分析必须写明分组字段、聚合函数、分母、单位、时间范围和缺失值处理；不能仅凭图形外观推断统计口径。
- **非图表方法**：网络布局、层级布局、空间剖分和几何包络虽在 RAWGraphs 菜单中以图表形式提供，但不都属于狭义的统计图表。本文保留其技术身份，不强行归入同一种统计方法。

## 六、核心结论

RAWGraphs 的图表实现可以理解为一条处理链：

**数据字段 → 维度映射 → 分组/聚合/派生计算 → 图形布局算法 → 视觉通道 → 标签、图例与交互配置。**

研究统计图形时，最重要的不是先问“这是什么形状”，而是先问：**数据是什么、计算了什么、什么视觉属性承载了计算结果、读者因此能够比较或发现什么。**
