# 叙事框架搭建

## 阶段目标

从基础数据集中选择有解释力的字段组合，建立清晰的叙事主题、信息单元和阅读路径。

## 子文件夹

- [01-叙事主题与核心观点](01-叙事主题与核心观点/README.md)：用一句话表达作品要回答的问题和核心发现；区分事实陈述、解释性观点与需要验证的假设。
- [02-字段组合与信息单元](02-字段组合与信息单元/README.md)：记录哪些基础字段组合成一个信息单元，说明组合逻辑、所表达的含义、所需数据和输出形式。
- [03-叙事顺序与阅读路径](03-叙事顺序与阅读路径/README.md)：规划读者从哪里开始、如何分段、先看到什么后看到什么，以及主线、支线和信息层级。
- [04-叙事草图与框架验证](04-叙事草图与框架验证/README.md)：用文字大纲、卡片排序、线框图或低保真草图验证信息是否连贯，检查跳跃、重复和证据不足。

## 阶段交付物

叙事主题陈述、核心观点、字段组合表、信息单元清单、叙事顺序与结构草图。

## 阶段完成检查

- [ ] 关键选择有依据并留有记录。
- [ ] 输出可被下一阶段直接使用。
- [ ] 需要补充或验证的内容已列入项目总表。
