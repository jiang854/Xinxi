# 02｜主题内容分析

## 阶段目标

将主题转化为可设计的信息问题，并通过大模型协作形成有依据的分类判断。

## 子文件夹

- [01-主题边界与核心问题](01-主题边界与核心问题/README.md)：定义主题对象、时间/空间边界、核心问题、关键概念、主要对象及其关系。
- [02-数据逻辑判定](02-数据逻辑判定/README.md)：判断主题信息更接近编年、层级、编目、字母表、地理或多种逻辑组合；记录主逻辑、辅助逻辑和证据。
- [03-信息图形类型判定](03-信息图形类型判定/README.md)：从02模块的表现类型中选择主类型与辅助类型，例如混合型、文字/列表型、时间轴型、照片式、词云图型等；说明为何适用及不适用的类型。
- [04-视觉风格与设计标签](04-视觉风格与设计标签/README.md)：区分照片主导、平面矢量、插画、手绘、3D、拼贴等媒介/风格标签，以及ISOTYPE、图标、地图符号、词云等设计方法或图形模块。
- [05-大模型讨论记录](05-大模型讨论记录/README.md)：保存向大模型提出的问题、提供的材料、模型提出的候选分类、反例、证据核查、人工判断与最终决策。

## 阶段交付物

主题内容分析报告、数据逻辑判断、主/辅助表现类型、视觉风格与标签清单、大模型讨论记录。

## 阶段完成检查

- [ ] 子文件夹中的材料已归档。
- [ ] 关键判断、数据来源和处理过程有记录。
- [ ] 未解决问题已列入项目总表。
- [ ] 已形成可交接给下一阶段的成果。
