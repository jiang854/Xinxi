# 03｜数据搜集

## 阶段目标

围绕主题问题建立可追溯的数据与资料来源，不把未经核实的网络信息直接当作事实。

## 子文件夹

- [01-公共数据集](01-公共数据集/README.md)：收集政府开放数据、国际组织数据、研究机构数据、开放平台数据等；记录下载日期、版本、字段、统计口径与许可。
- [02-文本文献](02-文本文献/README.md)：收集书籍、论文、报告、档案、新闻、网页和访谈文本；记录作者、出版信息、页码、链接及可引用范围。
- [03-自建数据集](03-自建数据集/README.md)：记录自行观察、测量、访谈、标注、编码、拍摄或人工整理的数据；写明采样方法、纳入标准和误差来源。
- [04-来源授权与可信度记录](04-来源授权与可信度记录/README.md)：逐条记录来源机构、原始链接、发布日期/更新日期、许可协议、引用方式、可信度判断与待核实事项。

## 阶段交付物

数据来源清单、原始数据副本、文本文献目录、自建数据采集记录、版权与许可记录。

## 阶段完成检查

- [ ] 子文件夹中的材料已归档。
- [ ] 关键判断、数据来源和处理过程有记录。
- [ ] 未解决问题已列入项目总表。
- [ ] 已形成可交接给下一阶段的成果。
