# 设计实施

## 阶段目标

将已确认的叙事框架和视觉编码方案落实为可交付的信息图形作品，并保留制作过程。

## 子文件夹

- [01-构图与版式方案](01-构图与版式方案/README.md)：确定画布尺寸、方向、网格、信息分区、阅读路径、留白、标题与图例位置，保存不同版式方案及选择依据。
- [02-视觉稿与设计迭代](02-视觉稿与设计迭代/README.md)：保存低保真草图、视觉探索稿、阶段版本、评审意见和修改记录；记录每轮修改解决的问题。
- [03-数据图形与插图制作](03-数据图形与插图制作/README.md)：制作统计图形、地图、信息图形、插画、符号、图标和图像标注；记录数据版本、软件、参数和素材来源。
- [04-输出文件与交付规范](04-输出文件与交付规范/README.md)：归档最终印刷版、屏幕版、展览版或社交媒体版；记录尺寸、分辨率、色彩模式、字体处理、文件格式和交付清单。
- [05-过程归档与版本记录](05-过程归档与版本记录/README.md)：保存源文件、链接资源、字体/素材许可、版本号、变更摘要、备份位置和项目复盘。

## 阶段交付物

版式方案、视觉稿、制作源文件、最终输出文件、交付说明和版本归档。

- [ ] 该阶段的记录和材料已归档。
- [ ] 关键决策、修改与版本可追溯。
- [ ] 输出文件符合项目交付要求。
